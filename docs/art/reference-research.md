# 레퍼런스 조사와 역제안 (2026-11-25)

> 출발점: 사용자가 C3(칩멍크, 파스텔 소프트 셀, 서 있는 자세, 빨간 목끈 하나)를 가장 좋게 봄.
> 확정된 톤: 귀여운 캐릭터 + 현실처럼 잔혹한 결과(그래픽 잔혹 묘사 제외) = 블랙코미디.

## 1. 조사한 레퍼런스와 가져올 것

| 레퍼런스 | 핵심 문법 | 우리에게 적용 |
|---|---|---|
| 치이카와 (Chiikawa) | 아주 단순한 얼굴의 귀여운 캐릭터가 화폐 경제·자격증·일용직 노동이 있는 가혹한 세계에서 산다. 20~30대 직장인이 공감한다. | 가장 가까운 선례. 캐릭터는 단순하게, 가혹함은 세계와 제도에서. 얼굴이 단순할수록 감정이 오히려 크게 읽힌다. |
| 컬트 오브 더 램 (Cult of the Lamb) | 개발진: 귀여운 그림 덕분에 끔찍한 내용을 넣어도 너무 끔찍하게 느껴지지 않는다. 귀여움이 공포를 줄이면서 동시에 키운다. | 200종 파산 엔딩의 근거. 귀여움은 수위를 낮추는 장치이자 대비를 만드는 장치. |
| 다크 코지 게임 연구 | 부드러운 형태와 파스텔·탁한 색이 "시각적 안전감"을 지켜 준다. | 캐릭터는 파스텔로 안전하게, 사건 요소만 차갑게. |
| 어그레시브 레츠코 (Aggretsuko) | 산리오식 단순 귀여움 + 사무실 분노 풍자. 어른 대상. 데스메탈 노래방이 감정 배출구. | 주인공에게도 "배출구" 장치 하나: 탐욕이 오를 때만 나오는 표정이나 행동(예: 롱 버튼 연타 얼굴). |
| 나이트 인 더 우즈 (Night in the Woods) | 외곽선 없는 동화책 같은 그림, 의인화 동물의 "무심한 눈빛", 따뜻한 오렌지 대 불길한 파랑. 몰락하는 지역 경제와 우울. | 색 규칙: 캐릭터는 따뜻한 오렌지, 세계는 차가운 파랑. 현실 경제를 동물로 그리는 방식의 직접 선례. |
| 할로우 나이트 (Hollow Knight) | 캐릭터는 단순하고 세계는 복잡하다. 캐릭터가 배경보다 밝고, 굵은 외곽선이 배경에서 떼어 낸다. 표정 없는 얼굴이 오히려 귀엽다. | 모바일 가독성 규칙: 바깥 외곽선만 굵게, 캐릭터는 항상 배경보다 밝게. |
| 스밋코구라시 / 구데타마 | 불안·무기력을 가진 캐릭터, 최소한의 표정, 지친 젊은 직장인 공감. | 표정 수를 늘리기보다 작은 차이(땀 한 방울, 눈 반쯤 감김)로 감정 표현. |
| 잔망루피 | 원작 얼굴을 일그러뜨린 밈 짤에서 시작해 MZ 마케팅 성공. 다듬어진 그림보다 어색하고 투박한 얼굴에 공감. | 엔딩 카드에 "밈이 되는 일그러진 얼굴" 한 장씩. 공유 동기. |
| 레인즈 / 비트라이프 | 최소한의 화면, 부조리한 블랙 유머, 선택의 결과를 텍스트로 툭 던짐. | 엔딩 대사는 사실 그대로, 짧게. 그림은 상황 하나만. |
| 방치형 게임 일반 | 밝고 잘 읽히는 2D가 가장 좋은 평가. 그림보다 시스템이 핵심. | 그림체는 생산 비용이 낮아야 한다(엔딩 200장). |
| 칩멍크 실제 해부 | 등의 짙은 줄무늬 5줄, 눈 주변 얼굴 줄무늬, 짧고 둥근 귀, 다람쥐보다 덜 풍성하고 납작한 꼬리, 볼주머니. | 다람쥐와 구분되는 표식. 특히 **볼주머니**를 게임 장치로 쓸 수 있다. |

## 2. 역제안

> 2026-11-25 사용자 결정: 아래 "볼주머니 = 현금 게이지" 안은 거절됨. 기록으로만 남긴다.

### 제안 1: C3 진화형 + 볼주머니 게이지(거절됨) + 빨간 꼬리표
- **그림체**: C3 유지. 파스텔 소프트 셀, 할로우 나이트식으로 **바깥 외곽선만 굵게**. 캐릭터는 항상 배경보다 밝게.
- **볼주머니 = 현금 게이지**: 도토리(현금)가 많으면 볼이 빵빵하고, 빚이 늘면 홀쭉해진다. 숫자를 안 봐도 주인공 얼굴만 보면 형편이 보인다. 칩멍크를 고른 이유가 게임 안에서 생긴다.
- **빨간 목끈 → 빨간 꼬리표**: C3의 빨간 목끈을 **차용증 꼬리표**(가격표·압류 딱지 같은 꼬리표)로 바꾼다. 빚이 늘수록 꼬리표가 늘어난다. 귀여운 소품이 사실은 빚의 표식이라는 블랙 조크.
- **색 규칙**: 캐릭터는 따뜻한 오렌지·크림, 세계와 엔딩 배경은 차가운 파랑·회색 (나이트 인 더 우즈).
- 장점: 지금까지 고른 방향을 버리지 않음. 게임 장치와 캐릭터 디자인이 한 몸.
- 위험: 볼주머니 크기 단계를 몇 장으로 그릴지 생산 계획 필요.

### 제안 2: 치이카와 결 미니멀
- 얼굴은 점 눈과 작은 입, 몸은 둥근 떡 모양, 선은 가늘고 살짝 흔들리게. 감정은 땀·눈물·홍조 같은 기호로.
- 장점: 엔딩 200장 생산 비용이 가장 낮음. 공감과 밈에 강함.
- 위험: 치이카와와 너무 닮으면 아류로 보임. 줄무늬·볼주머니로 확실히 구분해야 함.

### 제안 3: 나이트 인 더 우즈 결 성인 감성
- 외곽선 없는 면, 반쯤 감긴 "무심한 눈빛", 따뜻한 캐릭터 대 차가운 세계.
- 장점: 현실 경제 풍자와 가장 잘 맞음. 성인 타깃에 강함.
- 위험: 귀여움이 약해져 블랙코미디 대비가 줄 수 있음. 작은 화면 가독성 확인 필요.

## 3. 공통 제안 (어느 방향이든)
1. **표정 체계**: 평소 표정은 적게, 탐욕이 오를 때만 나오는 "배출구 얼굴" 하나(어그레시브 레츠코), 엔딩마다 밈이 되는 일그러진 얼굴 하나(잔망루피).
2. **엔딩 일러스트 틀**: 캐릭터 1 + 상황 소품 1~2 + 차가운 배경. 대사는 한 줄, 사실 그대로(레인즈·비트라이프).
3. **가독성 규칙**: 바깥 외곽선 굵게, 캐릭터가 배경보다 밝게(할로우 나이트).
