메모:
- 스타일을 정하는 말은 맨 앞 `warm healing whimsical illustration` 하나뿐이다. 굵은 선, 원색 평면 칠, 점 눈 같은 특징은 프롬프트에 적지 않았는데도 모델이 그렇게 그렸다.
- 나머지는 장면 묘사다(누가, 어디서, 무엇을). 짧고 구체적이다.
- 체형 단어(`well-proportioned`, `balanced slim build`, `slender small`)를 써서 너무 통통해지는 것을 막았다.
- 우리 시험 그림(`docs/art/style-bold/`)은 이 프롬프트 대신 스타일 특징을 길게 풀어 쓴 프롬프트로 그렸다. 다음 시험은 이 짧은 형식을 따른다.
- 참고 그림의 곰은 기존 애니메이션 캐릭터와 닮았으므로 캐릭터는 가져오지 않는다.
