> 스타일 기준: `docs/art/STYLE_ANCHOR_v2.md` · 작업표: `docs/art/jobs/mvp_art_jobs.json` (21장)

## 2. 파일 이름과 크기

| 종류 | 원본 (git에 넣지 않음) | 앱에 넣는 파일 | 넣는 크기 | 화면에 보이는 크기 |
|---|---|---|---|---|
| 주인공 | `docs/art/mvp/raw/hero_*.png` | `public/art/hero_<상태>.webp` | 256×256 | 약 56×56 (지금 38 → 56으로 키우기를 제안) |
| 건물 | `docs/art/mvp/raw/bld_*.png` | `public/art/bld_<id>.webp` | 384×384 | 칸 약 120×110 안에서 약 88×88 |
| 집 | `docs/art/mvp/raw/house_*.png` | `public/art/house_<단계>_<id>.webp` | 384×384 | 건물과 같음 |
| 바닥 | `docs/art/mvp/raw/ground_tile.png` | `public/art/ground_tile.webp` | 256×256 | 96px 반복 |

- webp 품질 80 안팎, 투명 유지. 한 장 40KB 이하를 목표로 한다. 21장 합계 1MB 이하.
- 디스크가 4GB 남짓이다. 원본 PNG는 장당 1~2MB(배경 빼기 전후 2벌이면 21장에 약 60MB)이므로, webp로 옮기고 승인이 끝나면 `*.raw.png`는 지운다. 재시도 그림은 승인본만 남긴다.
- `docs/art/mvp/raw/`는 `.gitignore`에 넣는 것을 제안한다.

## 3. 마을 화면에 끼우는 법 (`src/ui/village/Village.tsx`, `src/styles.css`)

### 건물
- 지금은 `.bld .art` 안에 CSS 도형(`roof`, `body`, `win`, `door`)을 그린다. 이것을 건물당 `<img>` 한 장으로 바꾼다.
- `.art`는 폭 52%·최대 54px 제한을 풀고, 칸 폭의 약 80%를 쓰는 정사각형에 `object-fit: contain`, 아래 정렬.
- 모든 건물 그림의 바닥 판이 같은 위치에 있으므로, 같은 크기로 넣기만 하면 줄이 맞는다.
- 이름표(`.nm`)와 원금·연체 딱지(`.tag`)는 지금처럼 화면이 그린다. 그림에는 글자가 없다.

| 칸 id | 쓰는 파일 |
|---|---|
| `bank` | `bld_bank.webp` |
| `capital` | `bld_capital.webp` |
| `board` | `bld_board.webp` |
| `archive` | `bld_archive.webp` |
| `home` | `house_${houseStage}_${id}.webp` (0 tent, 1 cabin, 2 warehouse, 3 villa, 4 mansion) |
| `friends` | `bld_friends.webp` |
| `shark1` | `bld_shark1.webp` |
| `work` | 현재 일이 `pickup`·`flyer`면 `bld_work_street.webp`, 그 밖은 `bld_work_shop.webp` |
| `shark2` | 잠김이면 `bld_shark2_locked.webp`, 열리면 `bld_shark2_open.webp` |

- 잠긴 골목은 그림이 이미 어둡다. `.bld.dark`의 색 덮어쓰기는 빼도 된다.
- 선택된 칸 강조(`.bld.sel`)는 그대로 둔다.

### 주인공
- 지금은 `/hero.png` 한 장이다. 상태에 따라 다섯 장 가운데 하나를 보여 준다. 위에 있는 줄이 우선한다.

| 우선 | 상태 | 그림 | 조건 |
|---|---|---|---|
| 1 | 파산 | `hero_dazed` | 파산이 확정된 순간부터 재시작까지 |
| 2 | 위험 | `hero_sweat` | 연체가 하나라도 있거나, 열린 포지션의 현재가가 청산가에 가까울 때 |
| 3 | 기쁨 | `hero_joy` | 수익으로 포지션을 닫았거나 어느 채권처를 완납한 직후 1.5초 |
| 4 | 일하기 | `hero_work` | 노동 버튼을 누른 직후 0.3초 (지금의 통통 튐과 함께) |
| 5 | 평소 | `hero_idle` | 그 밖의 모든 때 |

- 다섯 장을 미리 불러 두어, 바뀔 때 깜빡이지 않게 한다.
- 통통 튐·이동 같은 귀여운 동작은 주인공에게만 준다. 건물은 움직이지 않는다.
- 모든 자세의 발 높이가 같으므로 그림을 바꿔도 발이 뜨지 않는다. 앉은 자세(`hero_dazed`)도 같은 바닥선이다.

### 바닥 (선택)
- `.scene`의 배경은 지금처럼 집 단계별 색(`--sky`, `--ground`)을 쓴다. 바닥 무늬는 회색 한 장을 `--ground` 색 위에 `background-blend-mode: multiply`로 얹어 다섯 단계 색을 그대로 살린다.
- 무늬가 건물을 방해하면 쓰지 않는다. 없어도 화면은 완성된다.

## 4. 검수 점검표

기준 그림(`bld_shark1`)
- [ ] 카메라: 약간 위에서 본 반측면 정면, 오른쪽 옆면이 조금 보인다
- [ ] 풀·흙 바닥판: 가운데, 그림 폭의 약 84%, 앞 모서리가 아래에서 약 8%
- [ ] 칩멍크나 다른 인물이 들어가지 않았다(참고 그림이 C3라서 생길 수 있다. 들어갔으면 참고 없이 다시 그린다)
- [ ] 이 그림이 통과하기 전에는 7~20번을 그리지 않는다

모든 그림
- [ ] 스타일 이탈 없음: 검은 외곽선, 사진 질감, 점토 같은 입체 광택, 수채 번짐이 없다
- [ ] 글자·숫자·로고가 없다. 간판과 전광판은 빈 색 판이다
- [ ] 빛이 왼쪽 위에서 온다
- [ ] 투명 가장자리: 배경 색(초록·자홍)이 테두리에 남지 않았고, 그림 안쪽에 구멍이 나지 않았다. 어두운 바탕과 밝은 바탕 양쪽에 올려 본다
- [ ] 잘린 곳이 없다(귀, 꼬리, 지붕 끝)

건물·집
- [ ] 같은 바닥: 15장을 반투명으로 겹쳤을 때 바닥 판이 겹친다. 어긋나면 그 장만 다시 그리거나 자르기로 맞춘다
- [ ] 같은 각도: 3×3으로 늘어놓았을 때 한 장만 다른 방향을 보지 않는다
- [ ] 100px 폭으로 줄여도 무슨 건물인지 읽힌다
- [ ] 숲속 마을: 숲 재료(통나무·껍질·뿌리·이끼·돌·잎 지붕)로 지었다. 현대 설비(실외기, 계량기, 알루미늄 새시, 물탱크, 전선, 콘크리트)가 없다
- [ ] 기능이 읽힌다: 은행은 반듯하고 차갑게, 오소리 사무실은 낡게, 캐피탈은 번들거리게. 하트·반짝이·사물의 얼굴이 없다
- [ ] 자홍 배경이라 건물에 분홍·보라가 없다. 잎 사이 틈에 자홍이 남지 않았다
- [ ] 집 5단계: 0에서 4로 갈수록 형편이 나아지는 것이 한눈에 보인다
- [ ] 독사 골목: 무서운 그림(해골·뱀·피)이 아니라 정갈해서 서늘하다
- [ ] 건물 색이 주인공보다 탁하다. 주인공을 건물 앞에 세웠을 때 주인공이 먼저 보인다

주인공
- [ ] C3와 같은 얼굴: 줄무늬, 크림색 볼, 빨간 목끈, 옷 없음
- [ ] 다섯 장의 머리 크기·키·발 높이가 같다(나란히 놓고 확인)
- [ ] 56px로 줄여도 표정 차이가 읽힌다. 특히 평소와 식은땀
- [ ] 식은땀·멍함에서도 귀엽다. 눈물·상처·더러움이 없다
