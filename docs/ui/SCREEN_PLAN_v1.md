# 선물의 숲 — 화면 기획 v1 (2026-11-25)

> 계기: 사용자 피드백 "UI 디자인 자체가 완전 별로인데… 이거 게임이잖아. 제대로 화면 기획부터 하고 짤래?"
> 이 문서의 모든 새 결정은 **[제안]** 이다. 사용자가 시안(`docs/ui/mockup_jobs.json`으로 그릴 6장)을 보고 방향을 고르면 [확정]으로 바꾼다.
> 바꾸지 않는 것(이미 [확정]): 탭 2개(마을·거래), 마을 = 모든 클리커, 대출은 건물에 직접 찾아가서, 집은 마을 속 외형만, 거래는 한 화면(스크롤·팝업 없음), UI는 "아주 간소화하고 귀엽게", 제도·숫자·문구는 현실 그대로.

## 2. 이 게임의 UI 원칙 7가지 [제안]

1. **상자 금지, 사물만.** 웹 카드처럼 보이는 둥근 사각형을 쓰지 않는다. 화면에 놓이는 판은 전부 숲 재료로 만든 사물이다: 통나무 간판, 나뭇잎 장부, 도토리 뚜껑 번호표, 도장, 쪽지. 사물로 만들 수 없는 것(HUD 숫자, 탭)만 화면 UI로 남기고 알약·나무 팻말 모양을 준다.
2. **마을은 한 장의 풍경이다.** 건물은 칸이 아니라 땅 위에 서 있고 길로 이어진다. 하늘·나무·길이 보인다. 스크롤 없이 한 화면(GDD 4.1 유지).
3. **누르는 것은 칩멍크다.** 클리커의 대상은 버튼이 아니라 주인공과 그 주변(일터 무대, 장부 위 도장). 누를 때마다 칩멍크의 자세·소품이 반응한다. (금지: 볼주머니 = 현금 게이지. 사용자 거절 사항)
4. **가는 것이 보인다.** 건물을 누르면 칩멍크가 길을 따라 걸어가고, 화면이 그 건물로 다가간다. 대출은 그 자리에서만 열린다.
5. **틀은 귀엽게, 내용은 차갑게.** 나무·종이·도장 같은 틀은 귀엽다. 그 안의 숫자·용어·약관·대사는 현실 그대로 정확하게. 장부에 하트·반짝이를 넣지 않는다(톤 문서 1장).
6. **한 화면에 주 버튼 하나.** 주황 주 버튼은 화면당 하나(거래 화면만 롱·숏 한 쌍). 나머지는 나무색 보조 버튼이나 칩.
7. **반응은 작게 자주, 크게는 세 번만.** 누를 때마다 작은 반응(숫자 떠오름, 도토리 한 알, 통통 튐). 화면 흔들림·큰 도장·정적은 **완납, 강제 청산, 파산** 세 순간에만.

## 3. UI 재료와 스타일 키트 [제안]

그림(건물·캐릭터)의 스타일은 `STYLE_ANCHOR_v2.md`가 정한다. 이 장은 **화면 UI 틀**의 스타일이다. 둘을 섞지 않는다: UI 틀은 그림보다 단순하고(면 2톤, 질감 없음), 그림을 가리지 않는다.

### 3.1 재질 3가지
| 재질 | 생김새 | 쓰는 곳 |
|---|---|---|
| 통나무 판 | 따뜻한 갈색 면, 위쪽에 밝은 줄 하나, 아래쪽에 짙은 두께 4~5px, 모서리 반지름 14. 나뭇결은 짧은 선 2~3개만 | 탭 바, 건물 이름표, 장소 화면의 창구 틀, 버튼 |
| 나뭇잎 종이 | 크림색 면, 가장자리가 살짝 울퉁불퉁(반지름 불규칙 10~16), 연한 잎맥 한 줄. 테두리는 짙은 크림 1.5px | 장부, 약관, 속보 띠, 쪽지, 엔딩 카드, 말풍선 |
| 도장 잉크 | 붉은 잉크 테두리 + 글자, −6~−12도 기울임, 가장자리 살짝 끊김 | 연체 딱지, 도장 자국, 완납, 파산, 200배 경고 |

9칸 늘이기(9-slice) 그림 3장(통나무 판, 나뭇잎 종이, 알약)이면 대부분 만든다. 그림 없이 CSS만으로 먼저 만들 수 있게 값도 적는다(3.4).

### 3.2 버튼
| 종류 | 생김새 | 크기 | 상태 |
|---|---|---|---|
| 주 버튼 | 도토리 주황 면, 위 1/3에 밝은 띠, 아래 두께 5px(짙은 주황갈색), 반지름 18, 글자 짙은 갈색 | 높이 56~64 | 누름: 4px 내려가고 두께 1px, 80ms. 꺼짐: 바랜 나무색 + 글자 60% + 이유 한 줄 |
| 보조 버튼 | 통나무 판(밝은 나무), 아래 두께 4px | 높이 48~56 | 같음 |
| 도장 버튼 | 둥근 도장 손잡이 모양(위는 나무 손잡이, 아래는 붉은 고무면이 살짝 보임) | 72×72 원 또는 높이 56 | 누름: 장부 쪽으로 내려찍힘 + 자국 |
| 칩 | 도토리 뚜껑 모양 알약. 선택되면 짙은 갈색 면 + 크림 글자 + 1px 내려앉음 | 높이 44 | 색만이 아니라 "내려앉음"과 ✓로도 선택 표시 |
| 롱 / 숏 | 주 버튼과 같은 두께. 롱은 ▲, 숏은 ▼ 큰 화살표 + 글자. 색은 설정의 상승·하락 색 | 높이 64, 각 폭 절반 | 포지션 방향과 반대 버튼은 꺼짐 |

모든 누르는 것 44×44 이상, 서로 8 이상(GDD 17장).

### 3.3 HUD 알약
장면 위에 떠 있다. 크림 면 + 짙은 갈색 테두리 2px + 아래 그림자 2px. 왼쪽에 아이콘이 알약 밖으로 반쯤 튀어나온다(게임 HUD의 전형).

| 알약 | 아이콘 | 내용 | 크기(390 기준) | 상태 |
|---|---|---|---|---|
| 현금 | 도토리 | `100,000` (가장 큼, 22pt) + 아래 작은 글씨 `순자산 −200,000`(음수면 빨강) | 폭 148 × 높이 40 | 늘면 숫자가 굴러 올라가고 도토리가 통 튐. 줄면 한 번 움찔 |
| 빚 | 접힌 나뭇잎 장부 | `빚 300,000` | 폭 112 × 높이 32 | 연체가 있으면 알약 오른쪽 위에 연체 딱지 |
| 정산 | 종 | `42초` + 고리 모양 남은 시간 + 아래 작은 글씨 `−9,000` | 폭 96 × 높이 40 | 10초 이하: 종이 흔들리고 고리가 빨강, 숫자가 초마다 한 번 커짐 |

- 도감 `n/200`은 HUD에서 빼고 **마을 기록관 건물의 이름표**에 쓴다(`기록관 12/200`). 거래 탭에서는 보이지 않는다. → GDD 15.1과 다름, [제안].
- 순자산은 현금 알약 안의 둘째 줄로 내린다.

### 3.4 색 토큰
`STYLE_ANCHOR_v2.md` 팔레트에서 뽑았다. 마을 색감 5벌(`data-stage`)은 하늘·땅·나무 색에만 적용하고, UI 틀 색은 단계와 무관하게 고정한다(틀까지 탁해지면 읽기 어렵다).

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--ink` | `#4A3120` | 글자, 테두리(검정 금지. 짙은 갈색) |
| `--ink-soft` | `#7A5C45` | 보조 글자 |
| `--paper` | `#FBF1DC` | 나뭇잎 종이, 알약 면 |
| `--paper-edge` | `#E6D3AE` | 종이 가장자리, 구분선 |

### S2. 장소 방문

건물을 누르면: 칩멍크가 길을 따라 걸어감 → 화면이 그 건물로 다가가 건물이 위쪽에 크게 놓임 → 아래에서 **창구**(통나무 틀 + 나뭇잎 장부)가 올라온다. 화면 전환이 아니라 같은 마을의 한 곳을 가까이 본 것이다. HUD와 탭 바는 그대로 있다.

### S4. 정산 · 연체 · 속보

정산은 45초마다, 어느 탭에서든 온다. 플레이를 멈추지 않는다(팝업 금지).

정산 순간     🔔( 정산 )       종 "땡" → 고리 다시 참

마을 탭에서 정산 순간:
   ╭────╮          ╭────╮           ╭────╮
   │오소│ −6,000↑  │캐피│ −3,000↑   │내집│ −5,000↑    건물 머리 위 숫자(1.2초)
   ╰────╯          ╰────╯           ╰────╯            급여는 일터 팻말 위 +1,500
 ≈≈ 정산: 급여 +1,500 / 이자 −9,000 / 유지비 −5,000 ≈≈  속보 띠 한 줄

   ╭────╮
   │오소│ ╱연체 1/2╱   ← 붉은 딱지가 "탁" 붙음(3배 → 1배, −8도)
   ╰────╯
 ≈≈ 오소리 대부 연체 1/2. 다음 정산까지 이자를 내지 못하면 끝입니다. ≈≈
   + 빚 알약 오른쪽 위에 작은 연체 딱지, 마을 탭 팻말에도 딱지, 칩멍크 식은땀

| 요소 | 규칙 |

### S6. 기록관(도감) · 전광판

둘 다 전체 화면. 왼쪽 위 `‹ 마을` 팻말. 건물 안으로 들어온 느낌으로 위에 그 건물의 재질(기록관 = 이끼 낀 돌과 선반, 전광판 = 통나무 기둥)을 머리띠로 두른다.

- 200장을 한 번에 그리면 느리므로 보이는 줄만 그린다(구현 메모).

### 5.2 방향 결정 [확정 2026-11-25 사용자]
- **전체 틀: B 말랑한 잎사귀 버블.** 둥근 파스텔 버블, 흰 테두리, 젤리 버튼. A·C는 쓰지 않는다(시안은 `docs/ui/mockups/`에 남김).
- **거래 화면은 심플하게. 차트는 깨끗한 사각 영역**: 칩멍크 얼굴·잎 장식·틀 장식이 차트 사각형 안으로 들어오거나 덮지 않는다. 장식은 차트 바깥(위 종목 탭, 아래 팻말·버튼)에만. 사용자 원문: "거래화면을 심플하게. 디자인이 사각 차트를 침범하지 말라는 말".
  - 그래서 S3의 "차트 판 구석 칩멍크 얼굴"은 뺀다. 칩멍크 표정이 필요하면 수익 팻말 옆 작은 얼굴로만(차트 밖).

### 5.3 새로 필요한 그림 (방향이 정해진 뒤 작업표로)

### 구현 순서 제안
1. 토큰·글꼴·버튼 3종·알약(3장) — 화면 전체 인상이 여기서 바뀐다.
2. S1 풍경 배치 + 일터 무대(패널 제거).
3. S2 창구(금융 → 친구 → 집).
4. S3 거래 모양.
5. S4 띠·딱지, S5 카드, S6 앨범.
각 단계 뒤 390×844와 360×640 스크린샷으로 "한 화면에 다 보이는가"를 확인한다.

## 6. 시안 방향 3가지 (`docs/ui/mockup_jobs.json`)

구조(4장의 배치)는 세 방향 모두 같다. 다른 것은 **틀의 재질과 분위기**다. 각 방향마다 S1 마을, S3 거래 2장씩 6장.

| 방향 | 한 줄 | 틀 | 버튼 | 어울리는 점 | 걱정 |
|---|---|---|---|---|---|
| **A. 통나무 간판 + 나뭇잎 종이** | 마을의 사물로 만든 UI | 통나무 판, 밧줄, 크림 나뭇잎 종이 | 두께 있는 나무·주황 버튼 | 숲속 마을 세계관과 가장 잘 맞음. 이 문서의 기본안 | 나무색이 많아 무거워질 수 있음 |
| **B. 말랑 잎사귀 버블** | Cats & Soup처럼 가볍고 둥근 | 흰 테두리의 파스텔 둥근 버블, 잎사귀 모양 꼬리 | 둥근 젤리 버튼, 원형 아이콘 버튼 | "아주 간소화하고 귀엽게"에 가장 가까움. 장면이 넓게 보임 | 현실의 차가움(장부·숫자)이 약해 보일 수 있음 |
| **C. 장부와 도장(스크랩북)** | 빚 장부에 스티커와 도장을 붙인 듯 | 크림 종이 스티커(두꺼운 흰 테두리 + 그림자), 줄 쳐진 장부, 붉은 도장 | 스티커 버튼, 도장 버튼 | 게임의 핵심 사물(장부·도장·딱지)이 UI 언어가 됨. 블랙코미디 톤 | 종이가 많아 다시 "문서 앱"처럼 보일 위험 |

고르는 기준: ① 첫눈에 게임으로 보이는가 ② 칩멍크가 화면의 주인공인가 ③ 숫자가 한눈에 읽히는가 ④ 거래 화면이 한 화면에 답답하지 않은가.

시안 그림은 방향을 고르기 위한 것이다. 그림 속 한글·숫자는 틀릴 수 있으니 글자가 아니라 **재질·배치·분위기**만 본다.
