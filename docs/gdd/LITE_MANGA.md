# 라이트 모드 만화 (구현 기록)

원본 콘티는 `docs/gdd/LITE_CONTI.md` 이다. 이 문서는 그 콘티가 화면에 어떻게 들어갔는지, 그림 파일과 풍선 자리, 숫자의 출처, 컷이 뜨는 조건을 적는다.

- 주소: `?proto=1&lite=1` (라이트가 아닐 때는 지금 게임 그대로)
- 그림: sprite-gen codex 컬러 만화 컷. 참고 그림은 `docs/art/v5/manga/p1_color.png`(첫째), `docs/art/v5/golden/hero_phone.png`, 대부업자가 나오는 컷은 그 인물의 `docs/art/v5/raw/c_*.png`. 오소리 대부는 v2 로 고정(`docs/art/v5/golden/BOSS_V2.md`, 기준 `boss_v2_ref.png`, 모델 시트 `boss_v2.png`). 프롬프트는 `docs/art/v5/prompts/manga_*.txt`, 원본 PNG 는 `docs/art/v5/manga/`, 게임에 들어가는 웹 사본은 `src/ui/proto/img/manga/*.webp`(1080×720).
- 말풍선은 비워서 그렸다. 한글 대사, 효과음, 숫자는 전부 화면이 HTML/SVG 로 얹는다(`src/ui/proto/lite/manga.ts` 의 % 자리).
- 효과음 글씨: 굵은 검정 글자에 흰 외곽선, 살짝 기울임, 통통 또는 떨림. 움직임 줄이기면 흔들지 않고 나타나기만 한다.
- 프롤로그: 한 쪽씩 화면에 맞춰 띄우고 누르면 다음 쪽. [건너뛰기]는 두 번째로 볼 때부터만 보인다. 세로 쪽(2:3, 정사각)은 390 폭 폰에서 쪽 전체가 한 화면에 들어간다(약 366×550). 절망의 표제지(원작 7쪽)도 2026-11-28 3차부터 세로 한 쪽(2:3)이라 자르지도 훑지도 않는다(가로 쪽을 훑는 CSS `.lp-sheet.wide` 는 가로 그림이 다시 생길 때를 위해 남겨 둔다).
- 짧은 시퀀스(파산, 환생, 새 대부업체): 세로 화면에서는 컷이 한 쪽에 쌓이고(지난 두 컷은 어둡게), 새 컷이 하얀 섬광과 함께 박힌다. 가로로 넓은 화면은 한 컷씩.

드물게: 서로 20초 간격(청산, 청산 직전, C4 는 간격을 무시하고 줄을 선다). 청산 직전은 90초에 한 번, 기도는 2분에 한 번만(200배는 거의 판마다 청산 근처를 지나서, 회차 시험에서 9분 23판에 청산 직전이 여러 번 떴다). C1 과 C2 는 화면 위쪽에 뜨고 누름이 그대로 지나가서 [정리하기]를 가리지 않는다.

수익 인증서 물음은 라이트에서 대박 이상과 이번 생 신기록에만 뜬다.

## 4부. 끝

- 장면 D 파산: 엔딩 카드 앞에 프롤로그 4번째 쪽(원작 7, `parody_7`)을 다시. 해설 칸은 그대로 두고, 그 아래 흰 상자 두 줄에 진짜 숫자 「빌린 돈 {지금 빚 전부}」 「남은 돈 {손의 돈}」(판을 쥔 채 이자를 못 내 파산했으면 「, 판에 걸려 있던 돈 {증거금}」이 붙는다), 로고 부제 「제N화 파산」, 「신연재!!!」는 빠진다. 그다음 기존 파산 엔딩 카드.
- 장면 E 환생: 흰 칸 「다시, 어느 날」(프롤로그 첫 쪽의 「어느 날」을 받는다) → 같은 문 앞(m2) 「…이번엔 다르다.」, 추심원 「오늘이 이자 날입니다. 정산마다 3,000.」, 상자 「(다르지 않을 수 있다)」. 판은 첫 대출 뒤(손에 10만, 빚 40만).
- 장면 F 완납: 추심원이 장부를 덮는다 「완납입니다.」, 칩멍크 「…한 판만 더 할까.」 → [은퇴한다] [한 판 더 산다].
