# D2. 타깃 유저

## 타깃 (1~2문장)
블랙코미디 풍자와 방치형 수집을 즐기는 **20~30대 모바일 캐주얼 게이머**. 주식·코인 입문자부터 경험자까지 섞여 있으며, 금융 용어는 몰라도 "빚 굴리기"의 공포와 웃음을 느끼는 층을 우선한다.

## 선정 근거
사용자 결정: 혼합형 (방치형 캐주얼 게이머 + 선물/주식 경험층). 풍자 대상(금융 시스템)을 경험해 본 층과 웃음 포인트를 공유하는 층을 모두 노린다.

## 플레이 특성 (제안 — 사용자 확인 필요)
| 항목 | 값 | 상태 |
|---|---|---|
| 1회 플레이 시간 | 3~5분 세션을 하루 여러 번 | 제안 |
| 플랫폼 | iOS / Android 앱 (세로 9:16, 한 손 조작) | 확정 (D1 메타) |
| 조작 선호 | 탭 중심, 레버리지·롱/숏은 큰 버튼 | 제안 |
| 난이도 선호 | 파산이 잦아도 재도전 쉬움, 첫 판은 쉽게 | 제안 |
| 반복 동기 | 엔딩 도감 수집, 부 기준 랭킹 | 확정 (D1) |
| 보상 선호 | 즉각 피드백(도장·흔들림·사운드) + 장기 목표(부자 되기) | 제안 |

## 타깃이 제한하는 기능 (근거 포함)
1. **세션 짧음 → 오프라인 진행 필수**: 3~5분 세션이면 정산 주기가 세션 중에 돌아가야 함. 앱을 닫아도 정산이 누적되어야 하므로 F4(오프라인 시간 저장) 필수.
2. **한 손 세로 조작 → 복잡한 차트 조작 금지**: 확대·축소, 지표 설정은 제외. 레버리지·롱/숏·투입 비중은 큰 버튼 4~5개 이내.
3. **금융 지식 낮은 층 포함 → 용어 설명 필요**: 레버리지·청산·롱/숏은 툴팁 또는 첫 판 안내 필요 (L6 튜토리얼 간소화 대신 용어 안내는 유지).
4. **경험층 포함 → 고배율 리스크 정보 필요**: 청산가·ROE가 화면에 항상 보여야 함 (U 화면 필수 요소).
5. **반복 동기 → 도감과 랭킹이 세션 진입점에 있어야 함**: 도감 진척도와 내 순위를 메인 화면에서 확인 가능해야 함.
6. **온라인 랭킹 → 서버 필요 (타깃 제약이 아니라 D1 기능에서 파생)**: 랭킹 제외 시에도 타깃 경험은 성립하나, 경쟁 동기 약화. 서버 비용·개인정보 처리 검토 필요.

## 타깃 밖 (제외)
- 금융 전문 시뮬레이터를 원하는 층 (실제 차트 분석 깊이 기대) — 콘셉트가 풍자이므로 제외
- 장시간 집중 플레이(30분 이상 세션) 선호층 — 세션 설계와 맞지 않음
