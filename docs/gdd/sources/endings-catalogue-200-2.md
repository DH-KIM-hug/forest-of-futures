## 5. 파산 엔딩 데이터베이스 활용 규칙

1. **JSON 맵핑 매칭:**
   * 각 엔딩의 코드(`END-001` ~ `END-200`)는 게임 클라이언트의 `EndingDataSO` ScriptableObject 및 백엔드 JSON DB의 Key 값과 1:1 대응합니다.
2. **연출 처리:**
   * 각 엔딩 확정 시, 화면 중앙에 붉은색 **[파산 승인 (FORECLOSED)]** 도장 스탬프 애니메이션이 출력되며, 상단에 엔딩 코드와 타이틀, 하단에 블랙코미디 대사 및 해당 연출 모티프 일러스트 팝업이 노출됩니다.
3. **도감 등록:**
   * 최초 해금된 엔딩은 도감 아이콘의 `LOCKED` 상태가 해제되며 해당 일러스트와 획득 일시가 로컬 저장소(`PlayerPrefs` / `CloudSave`)에 영구 저장됩니다.
