# 경제 시뮬레이션 결과 — 정산 주기와 밸런스 숫자

- 작성: 2026-11-25 (기획 결정, 사용자 확인 전)
- 스크립트: `scripts/sim/sim.mjs` (Node 24, 외부 패키지 없음)
- 실행: `node scripts/sim/sim.mjs --runs 2000` (약 25초)
- 원자료: `scripts/sim/out/results.md`(표 전체), `scripts/sim/out/results.json`
- 입력 숫자: `data/balance.json`, `data/loans.json`, `data/jobs.json`, `data/markets.json` 을 그대로 읽는다. 숫자를 바꾸고 다시 돌리면 이 문서의 표도 다시 뽑을 수 있다.

## 1. 결론

| 항목 | 정한 값 | 근거 |
|---|---|---|
| 정산 주기 | **45초** | 후보 6개(15·30·45·60·90·120초) 가운데 목표 6개를 모두 충족한 유일한 값 (3장) |
| 정산 1회당 이자율 | 1금융 1% / 2금융 2% / 사채 1단계 4% / 사채 2단계 8%(+선이자 40%) | 2차 조정 결과 (5장) |
| 시작 상태 | 현금 10만, 빚 30만(2금융 15만 + 사채 1단계 15만) — 사용자 확정값 그대로 | 첫 정산 이자 9,000 도토리 |
| 노동 1회 수입 | 60 → 90(150회) → 130(500회) → 200(1,200회) 도토리 | 3차 조정 결과 (5장) |
| 정산 급여 | 0 → 1,500 → 4,000 → 8,000 도토리 | 방치·오프라인 수입 |
| 추세 세기 | 틱당 표류 = 변동성의 15%, 추세 평균 길이 약 150초 | 추세를 읽는 거래에만 기대 수익이 생기도록 (실험 4) |
| 거래 수수료 | 진입·정리 각각 명목 금액의 0.04% | 200배에서는 왕복 수수료가 증거금의 16% |

## 2. 방법

가상의 플레이어 7종을 각각 2,000번씩, 게임 시간 30분 동안 돌렸다. 틱은 1초다.

| 이름 | 하는 일 |
|---|---|
| idle | 아무것도 하지 않는다 |
| labor_casual | 노동만, 평균 초당 1회. 여윳돈으로 이자율 높은 빚부터 도장 |
| labor_normal | 노동만, 평균 초당 1.5회 |
| labor_diligent | 노동만, 평균 초당 2.5회 |
| trader_cautious | 초당 1.5회 노동 + 오소리 빚을 다 갚은 뒤부터 거래: 25배, 현금의 50%, 손절 -25% / 익절 +50%, 최근 60초 추세 방향으로만 진입 |
| trader_bold | 초당 1회 노동 + 처음부터 거래: 50배, 현금의 50%, 손절 -50% / 익절 +100%, 추세 방향 |
| reckless_200 | 노동 없음. 200배, 전액, 방향 무작위, 익절 +100%, 손절 없음. 끝나면 바로 다시 진입 |

게임 규칙은 GDD와 같다: 정산마다 급여 → 펀딩비 → 이자 납부(독사 → 오소리 → 캐피탈 → 은행 순) → 미납분은 원금에 더하고 연체 +1 → 연체 한도(사채 2회, 1·2금융 3회)에 닿으면 파산. 강제 청산 뒤 현금이 1,000 도토리 미만이고 빚이 남아 있으면 즉시 파산.

### 넣지 않은 것
- 종목은 도토코인 하나만 거래한다(다른 종목의 청산 속도는 실험 3에서 따로 쟀다).
- 속보, 친구 대출, 이사, 오프라인 진행, 추가 대출은 없다. 그래서 "빚을 더 내서 버티는" 플레이는 결과에 없다.
- 가상의 플레이어는 지치지 않고 실수하지 않는다. 사람은 표의 숫자보다 느리고 더 자주 망한다고 보아야 한다.

### 미리 정한 목표
| 번호 | 목표 | 왜 |
|---|---|---|
| C1 | 방치하면 4~10분 사이에 파산 | 첫 세션(3~5분) 안에는 안 죽지만, 두 번째 세션 안에는 이자의 무서움을 본다 |
| C2 | 느슨한 노동만: 10분 안 파산 10% 이하, 빚 청산은 20분보다 늦음 | 대충 눌러서는 버티기만 하고 벗어나기는 오래 걸린다 |
| C3 | 성실한 노동만: 파산 5% 미만, 빚 청산 중앙값 8~20분 | 노동은 안전한 바닥이지만 지루할 만큼 걸린다 |
| C4 | 신중한 거래: 파산 20% 이하, 30분 뒤 순자산 중앙값이 같은 노동량의 노동만 플레이보다 큼 | 거래가 의미 있는 가속 수단이어야 한다 |
| C5 | 무모한 200배: 5분 안 파산 80% 이상, 순자산 100만 달성 0.5~5% | 대부분 망하지만 대박 사례가 드물게 나와 랭킹 이야기가 된다 |
| C6 | 4분 세션에 정산 3~6회 | 한 세션에 정산의 긴장을 여러 번 겪는다 |

C2·C3·C4는 1차 실행 뒤 한 번 고쳤다(5장에 고친 이유). C1·C5·C6은 처음 정한 그대로다.

목표를 고친 곳
- C2: 처음에는 "느슨한 노동은 30분 안 빚 청산 20% 미만"이었다. 일자리가 노동 횟수로 열리게 한 뒤에는 누구든 오래 누르면 결국 갚으므로 "20분보다 늦음"으로 바꿨다.
- C3: "15~30분"에서 "8~20분"으로. 초당 2.5회를 10분 동안 누르는 것은 1,500회다. 그 이상을 요구하면 클리커가 아니라 고역이라고 판단했다.
- C4: "30분 안 빚 청산 비율"에서 "30분 뒤 순자산 중앙값 비교"로. 거래자는 거래 밑천을 남겨 두느라 빚 청산 시각이 늦게 찍혀서, 빚 청산 시각으로는 거래의 이득을 잴 수 없었다.

## 6. 알려진 약점 (플레이 테스트로 확인할 것)

1. **빚 구간은 노동이 지배한다.** 성실한 노동만으로 10분이면 빚을 갚는다. 신중한 거래의 이득은 30분 뒤 순자산 +11%(428,201 대 385,760) 정도다. 거래가 진짜 힘을 쓰는 곳은 빚 청산 뒤, 집값(50만 → 5,000만)을 모으는 구간이다. 초반부터 거래의 비중을 키우려면 노동 수입 배율을 0.75로 내리는 것이 가장 간단하다.
2. **무작위 진입도 25~50배에서 평균 ROE가 살짝 양수다**(+0.7%, +2.3%). 추세가 이어지는 성질 때문에 "손절 좁게, 익절 넓게"가 공짜 점심이 된다. 수수료를 0.05%로 올리거나 추세 세기를 13%로 낮추면 0 근처로 내려간다. 출시 전 조정 후보.
3. **가상의 플레이어는 빚을 더 내지 않는다.** 실제 게임에서는 대출로 버티거나 판돈을 키우는 사람이 많을 것이고, 그쪽이 파산 엔딩의 주 공급원이다. 이 부분은 시뮬레이션에 없다.
4. **속보(급등락 예고)가 없다.** 실제 게임에서는 속보가 200배 포지션을 더 자주 날린다.
