# D1. 한 문장 콘셉트

## 한 문장
플레이어가 **도토리 선물을 롱/숏으로 거래하고 빚을 탕감하며** **빚에서 벗어나 부자가 되는 것**을 목표로 하는, **방치형 클리커 + 선물 거래 시뮬레이션** 게임.

## 목표 위계
- **주 목표:** 빚에서 벗어나 부자 되기
- **부수 목표:** 파산 엔딩 200종 도감 수집 (더 대단해지기 위한 보상 축)
- **경쟁 축:** 부(富) 기준 랭킹 (별도 운영)

## 문장에서 역추론한 기능 목록
| 기능 | 근거 문장 요소 | 비고 |
|---|---|---|
| 선물 거래(5종목, 롱/숏, 레버리지 1x~200x, 증거금·청산) | 선물 거래 | 종목 5종 확정 |
| 정산 사이클(주기마다 이자 차감, 현금 0 미만이면 파산 판정) | 빚·방치형 | 주기 [TBD] (시뮬레이션 결과로 결정) |
| 대출 사다리(1~5단계, 빚 30만 도토리로 시작) | 빚 | 시작 상태 확정 |
| 원금 탕감 도장(채권처별) | 빚에서 벗어나기 | |
| 노동 클릭(도토리 줍기) | 방치형·클리커 | |
| 자산 등급(나무 텐트 → 오두막 → 창고 → 별장 → 저택, 담보·유지비) | 부자 되기 | |
| 부 계산(순자산) 표시 | 부자 되기 | 랭킹 지표로도 사용 |
| 파산 엔딩 판정·도감(200종) | 부수 목표 | 주 목표 아님 |
| 부 기준 랭킹 | 랭킹 별도 운영 | 온라인 기능. 콘셉트 성립에는 필수 아님 |
| 시세 실시간 피드 + 랜덤워크 대체 | 선물 거래 | |

## 신기능 판정 (3질문)
| 기능 | 콘셉트에 맞나 | 핵심 플레이를 강화하나 | 없어도 콘셉트가 성립하나 | 판정 |
|---|---|---|---|---|
| 엔딩 도감 200종 | ✔ | ✔ (재도전 동기) | ✔ (부수 목표이므로) | 포함 |
| 부 기준 랭킹 | ✔ | ✔ (경쟁) | ✔ | 포함 (사용자 결정), 온라인 의존 추가 |
| 실시간 시세 피드 | ✔ | ✔ | ✔ (랜덤워크로 대체 가능) | 포함, 대체 경로 필수 |
