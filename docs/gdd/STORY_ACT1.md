**돌려보내면**(1-2에서 연체를 고르면): 엔진 규칙 그대로다. 굴려서 번 돈은 전부 이자로 가고, 못 낸 이자는 원금에 얹히고(연체 1), 쳇바퀴에 가압류 딱지가 붙어 캐는 것의 3할이 원금에서 빠지고, 못 낸 생활비는 캐피탈 빚이 된다. 추심원: "못 낸 이자는 원금에 얹었어요오. 쳇바퀴엔 딱지 하나 붙이고 갈게요오. 캐는 것의 3할은 저희 거예요오." 다음 정산에 또 온다("한 번 더 밀리면 쳇바퀴 실어 가요오"). 두 번째 연체에 엄마의 쳇바퀴가 실려 가고, 세 번째에 파산한다. 그 사이 언제든 사무소에 가면 빌릴 수 있다.

## 2. 숨통 — 빌린 돈으로 사는 것들

집은 오두막 안이다. 쳇바퀴는 자산(한 대 50,000 고정, 자리 6칸), 알바 햄스터는 노동(들이는 값 없음, 일당 1,800/정산). **알바가 붙은 쳇바퀴만 혼자 돈다.** 주인공은 한 명이라 탭하는 동안만 굴린다.

| # | 사건 | 장면 | 숫자 |
|---|---|---|---|
| 2-1 | 첫 쳇바퀴에 알바 부르기 | 엄마의 쳇바퀴 안에 햄스터가 들어가 달린다. 주인공은 옆에 서서 폰을 든다 | 한 마리가 정산마다 6,500어치를 캐고(팔면 6,467) 일당 1,800 → 남는 돈 4,667(초당 25.9) |
| 2-2 | 빈 자리에 쳇바퀴 놓기 → 알바 부르기 | 방에 쳇바퀴가 한 대 더 선다. 알바가 없으면 "알바 없음" 딱지를 달고 서 있다 | 50,000 |
| 2-3 | 알바 둘 + 가끔 탭 | 집 요약 줄: 알바가 버는 돈 초당 51.9 ≈ 이자·생활비 초당 52.8. 탭을 조금 보태면 넘는다 | 정산당 +910(초당 3번 탭) |

복선: 엄마도 이 쳇바퀴로 이자를 냈다. 엄마의 빚이 어디서 왔는지(거래였나?)는 2막의 단서. 설명하지 않는다.

## 5. 1막의 끝 — 갈림길

- 빚을 다 갚으면: 대부 "깨끗하시네요. …그런데 이제 뭘로 사세요?"
- 갚기 전에 망하면: 청산 → 연체 → 알바가 나가고 → 쳇바퀴가 실려 가고 → 파산 엔딩 → 앨범 한 장 → 리본이 빛나고 다시 그 오두막, 그날(환생). 현금 0, 엄마 빚 30만, 쳇바퀴 한 대. 지도는 아는 길이라 열려 있고, 폰과 거래소는 다시 빌려야 받는다. 새 생의 추심원: "처음 뵙겠습니다아. 이자 4,500, 걷으러 왔어요오." 첫 수금 때 "빚은 사람이 아니라 장부에 붙어요."

## 튜토리얼 대사 v1

2026-11-26, DECISIONS_LOG U-32. 사용자: "게임하는 사용자 입장에서 아주 친절하게 튜토리얼 대사를 만들어. 쳇바퀴는 뭔지? 이 세계관이 뭔지 다 알아야 하잖아?"

처음 하는 사람이 **그것이 처음 필요해지는 순간에** 한 줄씩 듣는다(앞에서 몰아서 강의하지 않는다). 이야기 순서와 숫자는 위 0~3장 그대로이고, 대사만 늘리고 쪼갰다. 위 표에 적힌 옛 대사와 다르면 **이 절의 대사가 최신**이다. 구현: 대사 `src/ui/proto/guide.ts`(설명 줄) · `text.ts`(이야기 줄), 띄우는 때 `watch.ts guideCheck` · `tutorial.ts`, 화면 `CutIn.tsx`.

규칙
- **말하는 사람**: 오소리 추심원("~요오", 무심) · 오소리 대부(부드러운 존댓말, 웃으며 무서운 말) · 족제비 상인("~요~") · 칩멍크 속마음 한 줄. 새 내레이터는 없다. 화면 조각만 짚는 줄(지도, 포지션)은 지문 카드.
- **한 줄에 한 가지**, 390px 폰에서 두 줄 이하(자동 한 바퀴가 줄 수를 잰다). 탭하면 다음 줄.
- **비추기**: 설명하는 화면 조각만 밝게 두고 노란 테와 화살표를 단다(나머지는 어둡게). 조각이 화면 아래쪽이면 대사 카드가 위로 올라간다. 조각은 화면 코드의 `data-hl` 이름으로 찾는다. 집 화면의 조각은 아래 판의 상태도 정한다(U-34): 세상의 쳇바퀴·접힌 한 줄·정산 막대 = 판을 접고, 칸·견줌 막대 = 판을 편다.
- **평생 한 번**: 설명 줄(아래 표의 "설명 `이름`")은 화면에 뜬 순간 본 것으로 적히고(`localStorage fof.proto.guide.v1`) 다시는 나오지 않는다 — 다음 접속에도, 환생한 다음 생에도. 이야기 줄은 전처럼 그 생에 한 번. 이미 본 설명이 빠지면 장면은 이야기 줄만으로 짧아진다.
- **막지 않는다**: 강제로 기다리게 하는 시간이 없다. 카드 오른쪽 위 [설명 건너뛰기]는 그 장면의 설명을 전부 본 것으로 적고 닫는다(고를 것이 있는 장면은 고르는 줄로 간다). 설명이 떠 있는 동안에는 게임 시계가 멈춘다(정산 막대를 설명하는 사이에 정산이 오지 않게) — 닫으면 그대로 이어진다.
- **다시 보기·끄기**: 주소에 `&prologue=1`(프롤로그와 함께) 또는 `&guide=1` 이면 처음부터 다시, `&guide=0` 이면 전부 끈다. 장면 건너뛰기(`pdev`)에서는 꺼져 있다.
- 숫자는 전부 엔진 값을 끼운다(아래는 첫 생 기준 값).

2026-11-26. 튜토리얼이 끝난 뒤에도 인물들이 **내가 실제로 한 일**에 말을 건다. 숫자는 전부 엔진 값이다. 구현: 고르는 규칙 `src/ui/proto/react.ts`(거래·정산) · `ledger.ts`(장부), 대사 `text.ts STORY`, 띄우는 때 `watch.ts`. 급하지 않은 장면(문자·속보·족제비)은 포지션이 열려 있으면 닫힐 때까지 기다린다.

| 일어난 일 | 누가 | 대사 | 꼴 |
|---|---|---|---|
| 손익이 청구액의 5% 미만 | — | (아무도 말하지 않는다) | — |

**R2. 정산 알림**(다섯 번째 정산부터, 추심원 한 줄 + 내 정산 합계) — 위에서부터 처음 맞는 것

| 살림 | 대사 |
|---|---|
| 이자를 못 냈다 | 이자 n… 모자라네요오. (빌린 뒤라면 장면 R5) |
| 다음 정산에 모자란다 | 이자 n 수금 완료요오. 다음엔 모자라겠네요오. |
| 적자이고 3번 안에 바닥 | …이대로면 k번 뒤에 바닥이에요오. |
| 이번 생에 처음 남았다 | …남기 시작했네요오. 원금에 쓰셔도 돼요오. |
| 세 번째 연속 적자 | …세 번째 적자네요오. 제 일은 아니지만요오. |
| 포지션이 열려 있다 | …거래 중이시네요오. 이자는 이자대로 가요오. |
| 그 밖 | 이자 n 수금 완료요오. |

추심원은 오소리 대부의 이자만 걷는다. 다른 곳의 이자는 "다른 곳 이자 n은 자동이체."로 붙고, 오소리 빚이 없으면 "[자동이체] 이자 n 출금"만 뜬다.

**R3. 오소리 장부** — 사무소 카드 안의 장부(6% · 4% · 엄마 빚 1.5% 세 줄, 5만마다 금박 도장). 목표 막대: "오소리 장부 · 6% 빚부터 · 이자 −3,000 · n/50,000" → … → "엄마 빚 n만 남음". 금박 도장이 찍히면 "장부에 금박 도장이 찍혔다 · n개째". 줄이 지워질 때의 장면:

| 때 | 장면 |
|---|---|
| 처음 갚은 날(기존 4-5) | 지문 "사무소 벽에 액자들. 그 사이 빈 못 하나와 액자 자국." / 대부 "어머님보다 빠르시네요." |
| 6% 몫을 다 지웠다 | 대부 "6% 몫을 지우셨네요. 비싼 것부터. 영리하십니다." / "정산마다 이자가 6,000 줄었습니다. 제 몫이 준 거죠. 축하드려요." |
| 빌린 돈을 다 갚았다(엄마 빚 30만만 남음) | 대부 "빌려 드린 돈은 다 갚으셨네요. 이제 어머님 장부만 남았습니다." / 지문 "장부 첫 장. 엄마 이름 옆에 날짜가 줄지어 있다. 한 줄도 밀리지 않았다." |
| 엄마 빚 20만 | 지문 "장부 둘째 장. 빌린 까닭을 적는 칸이 먹으로 지워져 있다." / 대부 "그 칸은 어머님이 직접 지우셨습니다. 저는 안 읽었어요." |
| 엄마 빚 10만 | 대부 "10만 남았네요. 어머님도 여기까지는 오셨습니다." / 지문 "그 다음 줄. 엄마의 빚은 10만에서 다시 30만이 됐다. 날짜는 한겨울이다." |
| 엄마 빚 완납 | 지문 "장부 마지막 줄에 붉은 도장. 「완납」." / 대부 "어머님 빚, 다 받았습니다. 수고하셨어요." / 지문 "오소리 대부가 서랍에서 액자를 꺼내 빈 못에 건다. 뒤집힌 채로." / 대부 "그건… 다음에 보시죠." (+ 다른 빚이 남았으면 속마음 "…아직 다른 빚 n이 남았다.") |
| 모든 빚 0(기존 5장) | 대부 "깨끗하시네요. …그런데 이제 뭘로 사세요?" |

엄마의 빚이 어디서 왔는지는 여전히 말하지 않는다. 단서 셋(지워진 사유 칸 · 10만에서 다시 30만 · 뒤집힌 액자)은 [사용자 확인 필요].

**R4. 다른 돈줄** — 지도에는 사건이 있어야 그려진다

| 사건(조건) | 장면 | 열리는 것 |
|---|---|---|
| 튜토리얼이 끝나고 세 번째 정산(연체가 아닐 때) | 문자 "[숲속 캐피탈] 고객님~ 무담보 신용대출 정산당 2%! 쳇바퀴만 있어도 한도가 나와요~" / 속마음 "…지도에 가게가 하나 더 생겼다." | 지도에 숲속 캐피탈 + (잠긴) 숲속중앙조합 |

| 오소리 한도를 다 쓴 채 연체가 생겼거나, 캐피탈 한도까지 다 썼다 | 문자 "급전. 서류 없음. 뒷골목 끝, 잘 닦인 문." / 속마음 "…모르는 번호다. 내 번호는 어떻게 알았지." | 지도에 뒷골목 |
| 뒷골목에서 처음 [빌리기] | 독사 "급하신가 보군. 편하게 앉으시게." / "20만을 적고, 12만을 드리지. 나머지는 선이자일세." / "이자는 정산마다 8%. 적은 20만에 붙네." / "두 번 밀리면 받으러 가지. 조용히." → **[빌린다 +120,000 · 빚 +200,000] [돌아선다]** | — |

**R5. 무너지는 길** — 4장의 "청산 → 연체 → 알바가 나가고 → 쳇바퀴가 실려 가고 → 파산"이 장면이 된다

| 일 | 장면 |
|---|---|
| 빌린 뒤 이자를 못 낸 정산(번번이) | 추심원 "이자 n… 모자라네요오. 연체로 적을게요오."(두 번째부터 "이번 생 k번째 연체예요오.") / "못 낸 이자는 원금에 얹었어요오." / (딱지가 붙었으면) "쳇바퀴엔 딱지 붙였어요오. 캐는 것의 3할은 저희 거예요오." / "한 번 더 밀리면 실어 가요오. 싼 것부터요오."(남은 것이 없으면 "다음에도 밀리면 장부를 닫아요오. 그게 끝이에요오.") + 처음이면 기존 문자 4-4 |
| 일당을 못 받았다(이번 생 처음) | 족제비 "일당이 밀렸네요~ 햄스터 n마리, 데려갈게요~" / "원한은 없어요~ 장사니까요~ 돈 생기면 또 부르세요~" (그 뒤로는 한 줄) |
| 보조 쳇바퀴 압류 | 추심원 "보조 쳇바퀴 한 대, 실어 갈게요오." / "n 쳐서 원금에서 뺐어요오. 경매라 반값이에요오." |
| 엄마의 쳇바퀴 압류 | 추심원 "…어머님 쳇바퀴네요오." / "실어 갈게요오. n 쳐서 원금에서 뺐어요오." / 속마음 "…리본은 폰 고리에 묶여 있다. 그건 안 가져갔다." |
| 금리 인상 속보 | 도토리일보 한 장(기사 문구) / 추심원 "다음 2번은 이자가 n에서 m이에요오." / "위에서 정한 거라서요오. 저도 월급은 그대로예요오." |
| 파산 | 엔딩 카드. 1막에 없는 것(친구·조합·세금·대물림)과 빌린 적 없는 독사·캐피탈을 말하는 엔딩은 고르지 않는다 |

**R6. 환생 — 거래의 나무** (docs/gdd/SKILLTREE_TRADE.md) 환생 화면: "지난 생에 갚은 원금 n · 장부의 금박 도장 5만마다 하나 → 황금 실물 도토코인 +k", 그 아래 나무 한 그루. 뿌리 「손에 익은 앱」을 연 다음 생: 속마음 "…다시 그 오두막이다. 손에 폰이 쥐여 있다. 리본도 그대로다." 사무소에서 빌릴 때 대부는 폰을 주는 대신 "…그 폰, 어디서 본 것 같은데요. 리본이 눈에 익어서요."(환생을 설명하지 않는 유일한 틈). 마진콜 전화(B2): 대부 "여보세요, 오소리입니다. 도토코인 롱 200배, 청산이 코앞이에요." / "증거금 더 넣으시겠어요? 넣으면 버티고, 안 넣으면… 아시죠." → [넣는다] [빌려서 넣는다 · 금리 6%] [끊는다].

## 여는 순서 요약

집(프롤로그, 현금 0, 쳇바퀴 한 대) → 첫 정산 직전 추심원 → **지도**(사무소로 오라는 쪽지) → 사무소 대출 10만(4%) → **거래소**(중고폰) + 알바 부르기 → 첫 정산(이자 8,500 을 대출에서 뗌) → 알바·쳇바퀴 → 튜토리얼 거래(짜 둔 청산) → 두 번째 대출 10만(6%) → "실제 시세" 알림 = 튜토리얼 끝 → 거래(세상의 반응 R1) → 숲속 캐피탈 문자(R4) → 첫 상환 → 오소리 장부의 금박 도장(R3) → 200배 확인서 → 청산·연체·압류(R5) → (뒷골목 문자) → 파산 → 환생 = 거래의 나무(R6). 탭은 셋: 지도 · **집**(가운데) · 거래소.

## 정해야 할 것 [미정]

- 엄마 이야기의 단서를 어디까지, 언제 보여 줄지(오소리 사무소 벽, 장부의 날짜 등). → U-38 에서 장부 단서 셋을 넣었다(R3). 방향 확인 필요.
- 빚을 다 갚은 뒤 그 생을 어떻게 닫을지(은퇴를 고르게 할지, 그냥 이어 갈지).
- 단짝 다람쥐·곰 형을 2막에 다시 넣을지(1막에서는 뺐다).
- 오소리 대부가 첫 거래를 짜 놓았다는 것을 이야기 안에서 언제 들킬지(지금은 알림 한 장이 화면 밖 목소리로 말한다).
