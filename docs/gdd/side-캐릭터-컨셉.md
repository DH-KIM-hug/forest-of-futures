## 5. 조정 필요 (사용자 확정 요청)
1. **같은 종 충돌**: 주인공 다람쥐와 친구 다람쥐, 곰 3명(행동대장·친구·복덕방·경비원) — 종 또는 이름 구분 방식 결정
2. **여우 역할 과다**: 감정평가·변호사·사기 강사 — 1인 통합 vs 분리
3. **톤 기준**: 귀여운 파스텔 동화풍 + 블랙코미디 (PDF 대화 기준) — 맞는지
4. **엔딩 일러스트 범위**: 200장 전부 vs 대표 엔딩 N장 + 나머지 실루엣 (도감 잠금 표시에 실루엣 사용)
