## 1. 핵심 루프

### 1.1 분 단위 (한 번 접속 5~10분, 정산 3분)
```
        ┌─────────────── 현금 ───────────────┐
        │                                    │
  [갚는다]            [번다]              [건다]
  원금 탕감 도장      방치 자산 구매      거래 판돈
  이자가 준다(확실)   자동 수입이 는다    크게 불거나 사라진다
        │                │                   │
        └──── 3분마다 정산: 생활비·이자·유지비 ─────┘
                 못 내면 → 가압류 딱지 → 압류 → 파산
```
1. 일터를 누르거나(노동) 방치 자산이 번 돈이 현금으로 쌓인다.
2. HUD에 "다음 정산 수지"가 항상 보인다: `자동 수입 +5,130 / 나갈 돈 −10,000`. 이 숫자가 0 이상이 되는 순간이 **흑자 전환**이고, 그때부터 손을 떼도 버틴다.
3. 남는 현금을 도장·자산·판돈 가운데 어디에 둘지 고른다.
4. 속보 띠와 마을 말풍선에 정보가 흐른다. 따를지 말지 고른다.
5. 정산에서 못 내면 가압류 딱지가 붙고, 더 못 내면 자산이 하나씩 실려 간다. 가져갈 것이 없으면 파산.

### 1.2 접속과 접속 사이 (오프라인) [사용자 확정: 포지션 방치 / 제안: 정산 규칙]
| 무엇이 | 자리를 비운 동안 | 왜 |
|---|---|---|
| **포지션** | **전 구간 계속 돈다.** 청산·손절·익절·펀딩비가 서버 틱 기록의 실제 그 시각 가격으로 처리된다. 8시간을 비우면 8시간치가 전부 반영된다 | 걸어 두고 자는 것이 이 게임의 거래다. 돌아와서 결과를 발견한다 |
| **경제**(자산 수입·이자·생활비·연체) | 나간 뒤 **정산 2회(6분)까지만** 돌고 멈춘다. 접속하면 몫이 다시 찬다 | 3분 정산으로 8시간이면 160회다. 그대로 돌리면 자는 동안 누구나 파산한다 |
| **연체 보호** | 연체가 한도 − 1에 닿으면 그 전에 멈춘다. 자는 사이 연체로는 파산하지 않는다 | v1 규칙 유지 |
| **방치 자산 수입** | 경제와 같은 규칙(정산 2회분) | 이자와 수입이 같은 시계로 돌아야 공정하다 |
| **노동·구매·도장·진입** | 못 한다 | 접속 중에만 |
| **청산으로 빈손이 된 경우** | 자산도 없고 빚이 있으면 돌아왔을 때 파산이 기다린다 | "자고 일어나니 청산" |

- 하루 5번 접속하면 경제는 하루에 정산 22회쯤(접속 중 12~13회 + 오프라인 10회) 돈다. 한 세대는 실제 **1~3일**이다.
- 흑자 전환을 한 뒤에 나가면 돈이 조금 쌓여 있고, 못 하고 나가면 딱지가 붙어 있다. 포지션을 걸어 두고 나가면 결과가 기다린다.
- 오프라인 정산 몫(2회)을 자산 단계에 따라 늘릴지는 [TBD]. 5회로 하면 방치 자산이 너무 빨리 불어나 한 세대가 하루 만에 끝났다(시뮬레이션).

### 1.3 세대 (한 세대 실제 1~3일)
```
세대 시작(상속 방식 선택) → 빚·자산·거래 → 끝
   끝 ① 파산: 엔딩 한 장(가문 장부) → 재산 명세서 → 단순승인 / 한정승인 / 상속포기
   끝 ② 빚 없는 은퇴: 엔딩 없음 → 증여(자산·현금 그대로, 세금 빚) → 다음 세대
가문에 남는 것: 장부(엔딩), 최고 재산(랭킹), 유품, 기질, 채권처와의 관계, 마을의 흔적
```

## 2. 세 시스템이 물려 도는 방식 (빚 · 거래 · 방치 자산)

```
                     ┌──────────── 담보(자산 평가액의 50%만큼 한도 ↑) ───────────┐
                     ▼                                                         │
   ┌──────────┐  이자·연체   ┌──────────────┐   가압류 딱지(수입 30%)   ┌──────────────┐
   │   빚     │ ───────────▶ │    정산      │ ───────────────────────▶ │  방치 자산   │
   │ 5곳+세금 │ ◀─────────── │  (45초마다)  │ ◀─────────────────────── │   7단계      │
   └──────────┘  도장·압류분  └──────────────┘        자동 수입           └──────────────┘
        │  ▲                        ▲                                        ▲
 빌린 돈 │  │ 익절한 돈             │ 펀딩비·청산                              │ 경기
 (판돈)  ▼  │                       │                                        │ (최근 5분 지수 −2.5% → 수입 감소)
   ┌──────────────────────────────────────┐                                   │
   │            거래 (실제 시세)           │ ──────────────────────────────────┘
   │  정보: 속보·추천·소문·전단지·독사 정보 │    지수가 빠지면 가게 손님이 준다 → 숏으로 가게를 지킬 수 있다
   └──────────────────────────────────────┘
```

| 이것이 | 저것에 주는 영향 | 규칙 | 엔딩으로 이어지는 곳 |
|---|---|---|---|
| 빚 → 방치 자산 | 연체 1회에 가압류 딱지, 한도에 닿으면 자산 1개 압류 | 4.4 | 압류 연쇄(SEIZE) 15종, END-051·052·087 등 |
| 방치 자산 → 빚 | 자산 평가액의 50%만큼 캐피탈 한도가 는다. 가공점 이상은 조합 담보도 된다 | 6.3 | END-019·066(딱지가 겹침) |
| 방치 자산 → 정산 | 자동 수입이 정산 지출을 넘으면 흑자 전환 | 6.1 | 흑자 전환 전에 손을 떼면 8분 15초에 파산(시뮬레이션) |
| 거래 → 빚 | 청산 손실이 그 회차 미납액 이상이면 파산 원인이 '청산' 또는 '낚임'이 된다 | 7.2 | LIQ 45종, TIP 15종 |
| 빚 → 거래 | 빌리고 60초 안에 진입하면 포지션에 '빌린 돈' 꼬리표 | 7.3 | END-038·111·166 |
| 거래 → 방치 자산 | 지수(잣스닥) 최근 5분 수익률이 경기를 정한다. 불경기·공황에는 자산 수입이 줄고(고정비가 있는 자산은 더 크게), 호황에는 는다 | 6.4 | END-131·183 |
| 방치 자산 → 거래 | 가게가 큰 사람은 지수 숏이 보험이 된다(읽을 거리 하나 더) | 6.4 | - |
| 정보 → 세 시스템 모두 | 족제비는 추천과 함께 한도를 올려 주고, 독사는 정보와 함께 선이자 대출을 묶어 판다 | 5.6 | END-076·093·136·181·195 |
| 세대 → 세 시스템 모두 | 승계 빚, 물려받은 자산·단골, 정보 수첩(출처별 적중 기록)이 다음 세대의 출발점 | 3장 | LEGACY 15종 |

## 3. 세대 — 대물림 [사용자 확정: 방향 / 제안: 규칙·숫자]

### 3.1 이야기
- 1세대는 엄마다. 도토리 금융 위기에 전 재산을 잃었고 사고로 세상을 떠났다(화면 밖, v1 그대로).
- 플레이어는 **2세대**로 시작한다. 프롤로그에 한 장이 더해진다 [제안]: "상속을 포기할 수 있는 기간은 석 달이었다. 아무도 알려 주지 않았다." — 기간이 지나면 단순승인으로 본다는 실제 민법 규칙(법정단순승인)이 2세대가 빚 30만을 진 이유다. 그래서 첫 판에는 선택이 없고, **3세대부터 선택이 생긴다.**
- 세대가 끝나면: "세월이 흘렀다. 우편함에 나뭇잎 통지서 한 장 — 상속 개시." 부모가 어떻게 되었는지는 쓰지 않는다 [제안으로 채택 2026-11-25]. 엔딩 그림이 부모의 마지막 장면이다.

### 3.2 세대가 끝날 때 넘어가는 것

**항상 남는다(선택과 무관)** [제안]
| 것 | 내용 |
|---|---|
| 가문 장부 | 엔딩 도감이다. 쪽마다 "몇 대 누구의 결말"이 적힌다. 가계도 보기가 있다 |
| 가문 최고 재산 | 모든 세대를 통틀어 한 세대가 찍은 최고 순자산. 랭킹 기준 |
| 기질 | 부모가 망한 원인의 기질 1개 + 조부모의 기질 1개(최대 2개). 3.5 |
| 정보 수첩 | 출처별로 "몇 번 듣고 몇 번 맞았나". 플레이어가 배운 것을 가문의 기록으로 보여 준다 |
| 마을의 흔적 | 부모의 결말이 마을에 남긴 것(빈 집터, 남의 간판, 닫힌 문, 광장의 종이). 7.6 |
| 유품함 | 얻은 유품 전부. 몇 개를 **장착**할 수 있는지만 선택에 달렸다 |

**상속 방식에 달렸다** — 파산 엔딩 뒤 '재산 명세서' 화면에서 고른다. 왼쪽에 받는 것, 오른쪽에 떠안는 것, 아래에 "첫 정산 예상 수지"가 숫자로 나온다. 시간 제한은 없다.

| | 단순승인 | 한정승인 | 상속포기 |
|---|---|---|---|
| 한 줄 | 전부 받고 전부 떠안는다 | 받은 것으로 갚을 수 있는 만큼만 갚고 끝낸다 | 아무것도 받지 않는다 |
| **시작 빚** [사용자 확정: 빚 없이 시작하는 세대는 없다] | 승계 빚 + 세금. 합이 20만에 못 미치면 학자금으로 채운다. **20만 ~ 90만(+세금)** | 물려받는 빚 0 + **내 이름의 빚 20만 ~ 30만** | 물려받는 빚 0 + **내 이름의 빚 20만 ~ 30만** |
| 빚 | 승계. 단 ① 사채는 실제로 빌린 원금만(연체로 얹힌 이자 제외) ② 금리 상한 4% ③ 합계 상한 30만 × min(3, 1 + 연속 단순승인 횟수) ④ 처음 정산 3회는 이자 유예 | 0. 남은 자산·집을 경매(자산 50%, 집 70%)해서 빚을 갚고, 남으면 현금으로 받는다. 모자라도 더 갚지 않는다 | 0 |
| 방치 자산 | 남은 것 그대로 + **가업 간판**: 부모가 가져 본 가장 높은 단계의 한 단계 아래 자산 1개 | 없음(경매) | 없음 |
| 단골 | 자산 수입 +5% (대를 이을 때마다 +5%, 최대 +25%). 한 번 끊기면 0부터 | 0 | 0 |
| 집 | 부모의 집 그대로(빚이 붙어 있으면 그 빚도) | 부모 집이 창고 이상이면 오두막이 남는다(소액 주거 보호), 아니면 텐트 | 텐트 |
| 현금 | 남은 현금 + 3만 | 7만 + 경매 잉여금 | 7만 |
| 유품 장착 | 3칸 | 1칸 | 0칸 (유품함에는 남는다) |
| 채권처와의 관계 | 빚을 이어받은 곳은 **연줄**(한도 +20%, 첫 대출의 첫 이자 면제) | 떼인 곳은 **원한**(한도 −50%, 금리 +1%p, 한 세대 동안) | 떼인 곳은 **원한**, 그리고 독사 대부는 포기한 가문에 '당일 대출 전단지'를 두 배로 뿌린다 |
| 세금 | 순재산(자산·집 평가액 + 현금 − 승계 빚)이 30만을 넘으면 넘는 부분의 30% | 없음 | 없음 |
| 이럴 때 고른다 | 가업이 승계 빚의 이자를 감당할 때. 빠르고 위험하다 | 부모가 집이나 자산을 든 채 망했을 때(흑자 도산, 관계 파산) | 받을 것이 없고 승계 빚이 내 이름의 빚(20~30만)보다 무거울 때. 그래도 빚 20만은 진다 |

**빚 없이 은퇴(증여)** [제안]: 빚이 0이고 오두막 이상에 살면 전광판에서 "은퇴하고 물려주기"를 누를 수 있다. 엔딩은 없다. 다음 세대는 자산·집·현금을 그대로 받고 유품 3칸, 단골 +5%, 기질 **'금수저'**(노동 1회 수입 −50%)를 얻는다. 대신 순재산 30만 초과분의 30%가 **세금 빚**으로 붙고 정산 8회(6분) 안에 내야 한다. 못 낸 만큼 비싼 자산부터 공매(구매가의 50%)된다.

**빚 없이 시작하는 세대는 없다 [사용자 확정 2026-11-25]** — 상속을 포기해도, 한정승인을 해도, 부자 부모에게 증여를 받아도 시작 빚은 **20만 이상**이다.

| 빚의 이름 | 누구에게 | 얼마 | 왜 내 빚인가 |
|---|---|---|---|
| 학자금 대출 | 캐피탈(2%) | 15만 (포기·한정승인). 단순승인·증여는 다른 빚이 20만에 못 미칠 때 모자란 만큼 | 숲속학당 학자금. 부모가 아니라 내가 빌린 돈이라 상속과 무관하다 |
| 연대보증 빚 | 오소리 대부(4%) | 부모 사채 잔액의 50%, **5만 ~ 15만** (포기·한정승인) | 부모가 사채를 쓸 때 자식 이름으로 보증을 세웠다. 상속을 포기해도 **보증인으로서의 빚은 상속 채무가 아니라 내 고유 채무**라서 남는다(실제 법리 그대로) |
| 승계 빚 | 원래 채권처 | 상한 30만 × min(3, 1 + 연속 단순승인) | 단순승인 |
| 세금 빚 | 세무서 | 순재산 30만 초과분의 30%, 정산 8회 기한 | 증여·단순승인 |

- 하한 20만 / 상한: 포기·한정승인 30만, 단순승인 90만 + 세금, 증여는 세금만큼(20만 미만이면 학자금으로 채움).
- 포기·한정승인의 시작 현금은 7만이다(학자금에서 남은 돈). 2세대(빚 30만·현금 10만)보다 빚은 가볍고 손에 쥔 것은 적다.
- 앞 개정의 "포기 세대는 빚 0·현금 0"은 폐기했다. 집 단계별 생활비(4.1)와 세금 기한은 그대로 둔다.

> **"누구도 빚 없이 시작하지 않는다."** 가난한 집 자식은 부모의 빚이나 보증 빚을, 부잣집 자식은 세금 고지서를, 모두가 학자금을 들고 시작한다. 세금을 내려고 자산을 팔지, 담보 대출을 받을지, 거래로 메울지가 부자 세대의 첫 결정이다.

### 3.3 빚이 끝없이 불어나지 않게 하는 장치
| 장치 | 내용 | 시뮬레이션에서 본 것 |
|---|---|---|
| 승계 빚 상한 | 30만 × min(3, 1 + 연속 단순승인 횟수) → 최대 90만 | 3분만 하고 손을 떼는 가문이 8세대 내내 단순승인만 해도 시작 빚 중앙값은 30만 → 20만(하한)으로 **줄었다**. 빚내서 장사하는 가문은 상한 90만에 닿았고 넘지 않았다 |
| 시작 빚 하한 20만 | 빚 없이 시작하는 세대는 없다 | 5개 유형 × 4방식 × 1,000가문 × 8세대 전부에서 시작 빚 최솟값 200,000 |
| 사채는 원금만, 금리 4% 상한 | 독사 빚 8%가 그대로 넘어오면 첫 정산에 끝난다 | 승계 빚 30만의 첫 이자 ≤ 12,000 |
| 파산한 부모의 집은 경매(70%)로 빚부터 줄인다 | 단순승인해도 집에 붙은 빚이 통째로 넘어오지 않는다 | - |
| 이자 유예 3회 | 가업이 자리 잡을 시간 | END-032의 근거 |
| 포기는 언제나 가능 | 바닥이 있다: 빚 20~30만(금리 2~4%), 현금 7만, 텐트 | 포기로 시작한 세대의 파산율은 SIM_v2 실험 4 |
| 재산 명세서의 숫자 | "첫 정산 예상 수지"를 보여 준다. 권유 문구는 없다 | - |

### 3.4 세대마다 다르게 느껴지는 이유
1. **출발이 다르다** — 빚 30만과 가업 / 빚 0과 텐트 / 가게 세 채와 세금 고지서.
2. **기질이 다르다** — 부모가 망한 방식이 기본값을 바꾼다(3.5).
3. **시장이 다르다** — 세대마다 그 시각의 실제 시장이 걸린다. 조용한 시간에는 200배도 30분 동안 청산되지 않고, 거친 시간에는 1분 13초(중앙값)에 끝난다(5.3). 화면에는 "지금 장: 잔잔함 / 보통 / 격동"만 보인다.
4. **마을이 기억한다** — 원한 품은 창구, 문이 닫힌 친구 집, 부모의 간판을 단 남의 가게.
5. **장부의 빈칸이 다르다** — 이번 세대만 노릴 수 있는 엔딩이 있다(증여받은 세대의 파산 END-140, 포기한 가문의 재파산 END-055·148).

### 3.5 기질 [제안]
부모가 망한 원인 하나당 하나. 좋은 점과 나쁜 점이 한 쌍이고, **나쁜 점은 부모의 버릇을 기본값으로 만든다**(같은 방식으로 또 망하기 쉽다 = 대물림).

| 부모의 파산 원인 | 기질 | 좋은 점 | 나쁜 점 |
|---|---|---|---|
| 청산 | 한 방 체질 | 100배 이상 수수료 절반 | 배율 기본값이 50배, 손절 기본값이 '없음' |
| 낚임 | 의심병 | 정보마다 그 출처의 가문 적중률이 숫자로 보인다 | 속보가 3초 늦게 뜬다 |
| 사채 | 빚 내성 | 독사 선이자 40% → 30% | 독사 골목이 처음부터 열려 있다 |
| 제도권 | 서류 체질 | 담보인정비율 80% → 85% | 금리 인상 속보 때 이자가 2배가 아니라 2.5배 |
| 유지비 | 허세 | 집 단계별 한도 +20% | 집 유지비 +20% |
| 압류 연쇄 | 장사꾼 피 | 자산 수입 +10% | 가압류 딱지가 연체 1회 일찍(연체 예고 때) 붙는다 |
| 관계 | 외톨이 | 노동 1회 수입 +10% | 친구 소문이 절반만 들린다, 절교한 친구의 시작 신뢰 60 |
| 대물림 | 굳은살 | 노동 1회 수입 +15% | 재산 명세서의 한 줄이 가려진다 |
| (은퇴·증여) | 금수저 | 유품 3칸, 단골 유지 | 노동 1회 수입 −50% |

같은 원인으로 2대 연속 망하면 기질이 '진한 피'가 되어 두 효과가 모두 1.5배가 된다.

### 3.6 유품 [제안]
- 원인 8종에 하나씩. 그 원인의 엔딩을 5 / 15 / 30종 모으면 1 / 2 / 3단계가 된다(원인별 엔딩 수가 적은 곳은 3 / 6 / 9종). 효과는 작다(예: '찢어진 주문서' — 청산 직후 증거금의 3 / 6 / 10%를 돌려받는다).
- ★3 엔딩 가운데 12개는 고유 유품을 준다 [TBD: 목록].
- **유품 전당**: 오소리·독사 창구에 유품을 맡기면 한도와 별개로 5만 / 15만 / 40만(단계별)을 빌린다. 다 갚으면 돌아오고, 맡긴 채 파산하면 그 유품은 0단계로 돌아간다(END-083·099·125).
- 엔딩 수집이 부자 되기를 돕는다 — 이것이 두 목표를 한 방향으로 묶는 고리다.

### 3.7 이게 게임이 되는가 — 다른 게임과 견주어

| 게임 | 그 게임의 후계 규칙 | 재미의 원리 | 선물의 숲이 가져오는 것 | 다르게 하는 것 |
|---|---|---|---|---|
| Rogue Legacy | 죽으면 자식 셋 중 하나를 고른다. 자식마다 특성이 다르고, 모은 돈으로 성을 키운다 | 죽음이 다음 판의 재료가 된다. 실패해도 무언가 쌓인다 | 기질(부모가 망한 방식에서 나옴), 유품·가업으로 쌓이는 가문 | 자식을 고르는 대신 **받을 방식을 고른다**. 특성이 무작위가 아니라 내 지난 판의 결과다 |
| Crusader Kings | 군주가 죽으면 상속법대로 영지가 나뉜다. 좋은 것만 받을 수 없다 | 물려받은 것이 선물이자 짐이다. 가문의 이야기가 생긴다 | 단순승인의 "가게와 빚을 함께", 채권처의 원한과 연줄, 가계도 | 규칙이 하나(상속법 세 갈래)라 한 화면에서 끝난다 |
| Reigns | 왕은 반드시 죽고, 죽은 방식이 도감에 남는다. 다음 왕이 이어받는다 | 죽음이 수집품이다. 짧은 판이 긴 이야기로 이어진다 | 가문 장부(몇 대 누구의 결말), 일부 엔딩은 여러 대에 걸쳐야 열림 | 다음 세대의 숫자(빚·자산)가 실제로 달라진다 |

재미가 생기는 구체적 이유
1. **파산이 아깝지 않다.** v1은 파산하면 20분이 사라졌다. v2는 엔딩 한 장 + 기질 + 가업 간판이 남는다.
2. **망하는 순간에도 고를 것이 있다.** 재산 명세서는 이 게임에서 가장 무거운 버튼 세 개다. "가게를 지키려면 빚 26만을 져야 한다."
3. **잘 망하는 법이 생긴다.** 어차피 망할 판이면 자산을 남기고 망할지(가업 단계가 높을수록 간판이 좋다), 유품을 찾아 두고 망할지, 어느 채권처에 떼일지(원한)를 고른다.
4. **빚의 무게가 이야기와 같다.** 엄마 → 나 → 내 자식. 제도가 가난을 물려주는 방식을 버튼으로 겪는다. 블랙코미디의 대상은 여전히 제도다.
5. **시뮬레이션 근거**(SIM_v2 개정 5 실험 4, 정산 3분·포지션 방치·한 세대 3일): 자산을 사는 가문은 단순승인으로 시작한 세대의 3.3~23.7%가 또 망하고 포기로 시작한 세대는 0%다. 대신 6세대 뒤 가문 최고 재산 중앙값은 단순승인만 한 가문이 6.1억~10.5억, 포기만 한 가문은 확장형 104만·욕심형 209만(신중형은 3.4억)이다. 자산 없이 거래만 하는 가문은 어떤 방식을 골라도 세대마다 96.7~100% 망한다. 포기는 안전하지만 매번 빚 20만에서 다시 시작하고, 단순승인은 가업을 잇는다.

### 3.8 끝이 있는가 — 고리 끊기 [제안]
- **작은 끝(매 세대)**: 빚 없는 은퇴. 엔딩은 없고 가계도에 금빛 테두리.
- **참된 끝 「고리 끊기」**: ① 빚 없는 은퇴가 **2대 연속**이고 ② 그다음 세대가 세금을 기한 안에 다 냈을 때. 가문 장부 맨 뒤에 한 장이 생긴다: "도토리 금융 위기 이후 처음으로, 이 집 우편함에 독촉장이 오지 않았다." 프롤로그의 텐트와 같은 구도, 다른 색.
- 그 뒤에도 게임은 계속된다(번외 세대). 장부를 채우려면 누군가는 또 차트를 켜야 한다 — 이것까지가 농담이다.

- **V2-19** Given 밤 회차 / When 조합 창구에서 도장을 누른다 / Then "영업이 끝났습니다"가 뜨고 사건 기록에 `closed:bank`가 남는다.
- **V2-20** Given 독사에게 '이자 미루기'를 2번 썼다 / When 세 번째 신청 / Then 거절되고 사건 기록에 `rollover_refused`가 남는다.

## 5. 거래 — 실시간 시세 [사용자 확정 2026-11-25: **Hyperliquid 공개 WebSocket**(주) + DEX 체결가(보조)를 **게임 서버가 받아 가공해서** 앱에 준다 · 증폭 없음(배수 1)]

> 폐기한 초안: ① 앱에 넣은 기록 조각 재생 ② 앱이 거래소에 직접 연결 ③ 수익률을 증폭해 변동성 띠에 맞추기 ④ 바이낸스를 출처로 쓰기.

### 5.1 원칙
1. **움직임은 지금 이 순간의 실제 시장이다.** 모든 플레이어가 같은 시장을 본다.
2. **바꾸는 것은 이름과 가격대뿐이다** [사용자 확정 2026-11-25]. 실제 1초 수익률을 배수 1로 그대로 쓴다. 증폭도, 변동성 보정도 없다. 움직임의 크기는 레버리지(최대 200배)가 키운다.
3. **앱은 시세 출처에 직접 연결하지 않는다** [사용자 확정 2026-11-25]. 게임 서버가 받아 가상 종목·가격대로 바꾼 틱만 앱에 보낸다. 실제 가격은 앱에 들어가지 않는다.
4. **게임은 미래를 모른다.** 정보는 전부 지나간 시세를 읽는 규칙이고, 누가 맞는지는 정보 수첩이 실제로 재서 보여 준다(5.6).
5. **거래의 역할 [사용자 확정 2026-11-25]: "느리지만 안전한 노동·자산 vs 빠르지만 대부분 망하는 거래(+보험)".** 노동과 방치 자산은 며칠에 걸쳐 거의 확실하게 빚을 갚는 길이고, 거래는 걸어 두고 자면 대부분 망하지만 드물게 훨씬 빨리 끝내는 길이다. 자산을 가진 사람에게 거래는 보험(지수 숏)이 될 수 있다.
6. **포지션은 방치된다 [사용자 확정].** 앱을 꺼도 포지션은 서버 틱 기록대로 계속 돈다. 돌아와서 결과를 발견한다.

### 5.2 구조 — 서버가 받고, 가공해서, 앱에 준다 [사용자 확정: 구조·출처 / 제안: 세부]
```
주 출처   Hyperliquid 공개 WebSocket (키 없음) ─┐
보조 출처 DEX 체결가 (블록체인 RPC)            ─┴▶ 게임 서버 ──(가상 종목 1초 틱, WebSocket)──▶ 앱 (전원 같은 틱)
                                                   │
                                                   ├─ 시세 출처 어댑터 × 2 + 자동 전환
                                                   ├─ 변환기 (가상 종목·가격대, 지수 계산)
                                                   ├─ 틱 기록 저장 (오프라인 따라잡기 · 끊김 메우기 · 랭킹 검증)
                                                   └─ 틱 REST (지난 구간 내려주기)
```
| 부품 | 하는 일 |
|---|---|
| 시세 출처 어댑터 | 출처마다 하나. "초마다 종목별 가격·거래량·체결 방향 비율"이라는 같은 모양으로 내놓는다 |
| 자동 전환 | 주 출처가 5초 동안 조용하거나 값이 이상하면 보조 출처로, 주 출처가 60초 동안 정상이면 되돌아간다(5.4) |
| 변환기 | 실제 가격을 가상 가격으로 바꾼다. 지수(잣스닥)를 계산한다 |
| 틱 기록 | **원본 틱은 서버 안에만 둔다.** 앱에 내보낸 가공 틱을 따로 저장한다(1초 × 5종목 = 하루 43만 행, 30일 보관 [제안]) |
| 앱으로 보내기 | 1초에 메시지 1개: `{ 틱 번호, 시각, 종목별 [가상 가격, 거래량 지수, 매수 체결 비율], 시장 상태 }`. 접속하면 최근 1시간의 1분 요약을 먼저 준다(정보 규칙의 준비 구간) |
| 서버 위치 | 미국·캐나다 온타리오 밖(서울·도쿄·싱가포르 중 한 곳) — Hyperliquid 제한 지역을 피한다 |

**종목** [제안]

|---|---|---|---|

### 5.3 실제 가격 → 가상 가격 (변환식)
```
서버에서, 매초, 종목마다:
  mid(t)       = (최우선 매수호가 + 최우선 매도호가) / 2        ← 그 초의 마지막 값. 바뀌지 않았으면 그대로
  가상 가격(t) = 가상 가격(t−1) × mid(t) / mid(t−1)            ← 배수 1. 증폭·변동성 보정 없음 [사용자 확정]
  기준: 기준 시각에 가상 가격 = 가상 시작가(도토코인 68,000 등)
```
- 수익률은 실제와 **완전히 같다**. 다른 것은 가격대와 이름뿐이다.
- Hyperliquid 가격은 무기한 선물 가격이라 현물과 미세하게 다르다. 게임은 수익률만 쓰므로 상관없다.
- 출처를 바꿀 때(주 ↔ 보조)와 시장을 멈췄다 열 때는 **직전 가상 가격에서 이어 붙인다**(두 출처의 가격 차이를 움직임으로 치지 않는다).
- 기준 시각은 주 1회 다시 잡는다 [제안]. 열려 있는 포지션은 진입가·청산가·손절가를 같은 비율로 옮긴다(손익은 그대로).

**방치한 포지션이 청산될 확률** (SIM_v2 실험 3 — Hyperliquid 3분봉 10.4일, 증폭 없음, 무작위 진입, 손절 없음, 펀딩비 포함)
| 종목 | 배율 | 30분 안 | 2시간 안 | 8시간 안 (자고 일어나면) | 24시간 안 | 청산 시각 중앙값 |
|---|---|---|---|---|---|---|
| 도토코인 | 25배 | 0.1% | 1.7% | 8.8% | 24.8% | 10.5시간 |
| 도토코인 | 50배 | 1.4% | 9.2% | 31.0% | 58.9% | 7.5시간 |
| 도토코인 | 100배 | 7.7% | 28.0% | 59.9% | 82.4% | 3.6시간 |
| 도토코인 | 200배 | 29.7% | 60.5% | **84.5%** | 93.2% | 63분 |
| 멍도토 | 50배 | 1.3% | 10.7% | 35.4% | 61.3% | 6.5시간 |
| 멍도토 | 100배 | 11.1% | 34.7% | 64.1% | 85.1% | 3.0시간 |
| 멍도토 | 200배 | 36.9% | 65.4% | **84.5%** | 93.6% | 51분 |
| 삼솔전자 | 200배 | 41.0% | 67.6% | 84.4% | 93.6% | 42분 |

- **걸어 두고 자면 대부분 청산된다.** 200배는 8시간 안에 84~85%, 100배는 60~68%, 50배도 셋 중 하나다. 접속해 있는 6~9분 동안에는 거의 아무 일도 없지만(200배가 30분에 30~41%), 방치가 시간을 벌어 준다. 포지션 방치가 증폭 없는 시세의 느림을 푼다.
- 25배는 하루를 둬도 넷 중 셋이 살아 있다 — 저배율은 "걸어 두는" 쪽이고 고배율은 "던지는" 쪽이다.
- 펀딩비: 정산(3분)마다 명목의 0.001%. 8시간이면 명목의 0.16%(200배 증거금의 32%, 100배의 16%)라 오래 둘수록 청산가가 다가온다.
- **차트** [사용자 확정]: 세로축 자동 맞춤, 화면 전체가 몇 %인지 표시. 돌아왔을 때는 자리를 비운 구간 전체를 한 화면에 줄여서 먼저 보여 준다(7.5).

### 5.4 연결 규칙
**(1) 서버 ↔ Hyperliquid (주 출처)** — 2026-11-25에 이 기기에서 연결을 확인했다.
| 항목 | 규칙 |
|---|---|
| 주소 | `wss://api.hyperliquid.xyz/ws`, 키 없음 |
| 구독 | 종목마다 `{"method":"subscribe","subscription":{"type":"bbo","coin":"BTC"}}` — BTC·ETH·SOL·DOGE·XRP. 가격이 바뀔 때만 온다(BNB를 넣었던 시험: 10초에 BTC 105, ETH 93, SOL 89, BNB 41, XRP 80회. DOGE의 갱신 빈도는 다시 잰다 [TBD]). 거래량과 체결 방향은 `trades`를 함께 구독해 얻는다 |
| 쓰지 않는 것 | `allMids` — 문서상 폐지 예정이고 실제로 15초에 1회만 왔다. 대안으로 `fastAssetCtxs`를 검토할 수 있다 |
| 표본 | 서버가 1초마다 그 초의 마지막 mid를 찍는다. 그 초에 갱신이 없으면 직전 값(수익률 0) |
| 살아 있음 | 서버가 주기적으로 `{"method":"ping"}`을 보내 `pong`을 받는다. 5초 동안 어떤 메시지도 없으면 끊긴 것으로 본다. 연결 수·구독 수·보내는 메시지 수 제한은 공식 문서 값을 출시 전에 다시 확인한다 [TBD] |
| 재연결 | 1초 → 2초 → 4초 → … 최대 30초(±20%). 다시 붙으면 구독을 다시 보낸다 |
| 빈 구간 | Hyperliquid의 지난 기록은 `candleSnapshot`(가장 짧은 간격 1분, 최대 5,000개)뿐이라 초 단위로 메울 수 없다. 그래서 끊기면 메우지 않고 **보조 출처로 넘어간다** |
| 약관 | 속도 제한을 우회하지 않는다(3.1.8 합리적 사용). 연결 1개, 구독 10개 안팎이면 충분하다 |

**(2) 서버 ↔ 보조 출처 (DEX 체결가)**
| 항목 | 규칙 |
|---|---|
| 받는 것 | 각 체인 RPC(시작은 Alchemy 무료 등급 등, 매출이 생기면 자체 노드)로 해당 풀의 체결(Swap) 이벤트를 구독해 체결 가격·수량·방향을 얻는다 |
| 표본 | 1초마다 그 초의 마지막 체결가. 체결이 없으면 직전 값 |
| 주 출처와 다른 점 | 호가 중간값이 아니라 체결가다(풀 수수료만큼 위아래로 튄다). 체결이 드문 초가 많다. 블록 간격이 체인마다 다르다 |
| 평소 | 계속 받아 두되 내보내지 않는다. 주 출처 값의 이상 여부를 견주는 데 쓴다 |

**(3) 자동 전환** [제안]
| 조건 | 동작 |
|---|---|
| 주 출처가 5초 동안 조용함 | 보조 출처로 전환. 가상 가격은 직전 값에서 이어 붙인다. 앱에는 끊김이 보이지 않는다 |
| 주 출처의 1초 수익률이 보조 출처와 30초 넘게 0.5%p 이상 어긋남 | 이상값으로 보고 보조 출처로 전환, 운영자에게 알림 |
| 주 출처가 60초 동안 정상 | 주 출처로 복귀(다시 이어 붙임) |
| 두 출처 모두 5초 동안 조용함 | "시세 지연". 60초 넘으면 **시장 정지**(5.5) |
| 어느 출처로 내보냈는지 | 틱 기록에 남긴다(랭킹 검증과 사후 점검용) |

**(4) 앱 ↔ 게임 서버**
| 항목 | 규칙 |
|---|---|
| 연결 | 게임 서버의 WebSocket 하나. 1초에 메시지 1개 |
| 끊김 판정 | 3초 동안 틱이 없으면 끊김 |
| 재연결 | 1초 → 2초 → 4초 → … 최대 30초(±20%) |
| 빈 구간 | 서버의 틱 REST로 받는다(우리 서버의 가공 기록) |
| 앱이 가려질 때 | 연결을 닫는다. 돌아오면 오프라인 따라잡기 |

> **[폐기] 바이낸스** — 앞 개정은 바이낸스 `kline_1s` 결합 스트림을 주 출처로 썼다(연결 시험은 성공). 가공 데이터의 상업 이용 조건을 확인하지 못했고 내려받는 과거 기록이 비상업 조건(CC BY-NC-SA 4.0)이라, 사용자 결정으로 Hyperliquid로 바꿨다. 시세 출처 어댑터 구조는 그대로라서 필요하면 다시 붙일 수 있다. 세부 규칙(24시간 재연결, 20초 ping 등)은 DECISIONS_LOG M-8에 남아 있다.

|---|---|---|

**(3) 정보 수첩 — 적중률은 정하는 값이 아니라 재는 값**
- 출처마다 "말한 횟수 / 맞은 횟수"를 쌓는다. 맞음 = 말한 뒤 5분 안에 그 방향으로 평소 5분 변동 폭만큼 먼저 감. 따라 들어가지 않아도 센다.
- 가문 기록이다. 처음에는 비어 있고 세대를 거치며 찬다. 기질 '의심병'이면 말풍선 옆에 숫자가 바로 뜬다.
- 권유를 들려주는 게임이 아니라 **권유를 의심하는 게임**임이 화면에 드러난다.

- 정보를 본 뒤 20초 안에 같은 종목·같은 방향으로 들어가면 포지션에 **'정보 따라 진입: 출처'** 꼬리표가 붙는다(파산 원인 '낚임'과 `tipSource`의 근거).
- 족제비의 추천은 한도 상향과, 독사의 정보는 선이자 대출과 한 묶음이다 — 정보가 빚으로 이어진다(END-093·136).
- 게임 안 사건 예고(금리 인상 등)는 진짜다. 이것을 두고 NPC가 퍼뜨리는 소문("곧 금리 내린대")은 틀릴 수 있다 — 빚과 자산 쪽의 판단 거리다.

### 5.7 블랙코미디는 어디서 나오나
- 가장 친절한 입(족제비)은 오른다는 말만 한다. 누구 말이 맞는지는 그날 장이 정하고, 수첩을 채워 보면 다들 비슷하게 틀린다.
- 리딩방 전단지의 "적중 내역"은 전부 지나간 뒤에 적은 것이다.
- 속보는 사실이었다. 사실 다음에 무슨 일이 올지는 속보에 없었다(END-084).
- 방향이 맞아도 200배는 그 전에 청산된다(END-059).
- 200배를 걸었는데 시장이 조용해서 아무 일도 일어나지 않는다. 그 사이 이자가 나간다. 증거금에 묶인 돈 때문에 연체한다(END-031).
- 엔딩 화면은 누구 말을 듣고 들어갔는지를 그대로 되짚는다(7.5).

### 5.9 수용 기준 — 거래
- **V2-21** Given 같은 mid 열 / When 변환기를 두 번 돌린다 / Then 가상 가격 열이 같다.

## 6A. 쳇바퀴 채굴 — 클리커와 방치 자산의 새 뼈대 [사용자 확정 2026-11-25: 방향 / 제안: 규칙·숫자]

> 노동도 더 이상 완전히 안전하지 않다. 캔 것은 코인이고, 코인 값은 실제 시장이 정한다. "지금 팔까, 버틸까."

### 6A.1 한눈에
```
쳇바퀴를 돌린다(탭) ──▶ 코인이 지갑에 쌓인다 ──▶ 팔면 도토리(현금) ──▶ 도장 · 설비 · 판돈
        ▲                     │  값은 실제 시세대로 오르내린다
   채굴 설비(방치)             ├─ 전기세를 정산마다 지갑에서 먼저 뗀다(도토리로 정해진 값)
   쳇바퀴째 압류·담보          ├─ 정산 낼 현금이 모자라면 급매(수수료 3%)
                              └─ 폭락이 걱정되면 선물 숏으로 지갑을 지킨다(보험)
```

### 6A.2 규칙
| 항목 | 규칙 | 상태 |
|---|---|---|
| 캐는 종목 | 쳇바퀴 전체가 **한 종목**을 캔다. 접속 중 언제든 바꾼다(바꾼 뒤 캐는 것부터 새 종목). 지수(잣스닥)는 못 캔다 | [제안] |
| 1회 채굴량 | `(27 + 0.54 × 설비의 초당 순수입) ÷ 세대 시작 때 그 종목 가격` 개. 비싼 종목은 조금, 싼 종목은 많이 캔다(가격 반비례). 세대 시작 때의 가치로는 어느 종목이든 1회 27 도토리어치다 | [제안] |
| 캔 뒤의 가치 | 지갑의 코인 × 지금 가격. 세대 시작 때보다 10% 내리면 지갑도, 앞으로 캘 것도 10% 준다 | [사용자 확정] |
| 팔기 | 일터 패널의 [팔기](전부 / 절반 / 금액). 수수료 0.5%. **'캐는 즉시 팔기'** 스위치를 켜면 예전의 노동처럼 곧장 도토리가 된다 | [제안] |
| 전기세 | 설비마다 정해진 도토리 값(기준 매출의 70%). 정산 때 **지갑의 코인에서 시가로 먼저 떼고**, 모자라면 현금에서 낸다. 코인 값이 30% 내리면 설비는 역마진이다(돌릴수록 손해). 설비를 끄는 스위치가 있다(끄면 전기세도 0) | [제안] |

| 지갑과 빚 | 지갑 평가액의 50%가 캐피탈 담보 한도에 더해진다(값이 내리면 한도도 내린다). 연체 한도에 닿으면 **지갑이 먼저**(시가의 90%), 그다음 설비가 압류된다 | [제안] |
| 설비와 빚 | 설비 평가액(구매가의 80%)의 50%가 캐피탈 한도, 채굴 헛간 이상은 조합 담보(60%). 압류되면 쳇바퀴째 수레에 실려 간다(구매가의 50%만 빚에서 깎임) | [제안] |
| 오프라인 | 설비는 나간 뒤 정산 2회분만 캔다(1.2). 캔 것은 지갑에 쌓여 기다린다 | [제안] |
| 보험 | 지갑 평가액만큼 캐는 종목 숏(저배율)을 걸어 두면 폭락 때 지갑이 준 만큼 숏이 번다. 대가는 수수료와 펀딩비(8시간에 명목의 0.16%) | [사용자 확정] 구조 |
| 없어지는 것 | 도토리 줍기, 일자리, 자루·수레·가게, 6.4의 경기(코인 값이 곧 경기다) | |

읽는 법
- **뼈대는 유지된다.** 설비를 사서 바로 파는 사람은 36시간에 빚을 갚는다(자루·가게 시절과 같은 속도).

- **거래로 이기는 비율은 오르지 않았다**(0.5~0.7% 그대로).

### 6A.5 화면에 미치는 영향 [제안]
- **마을 일터 = 쳇바퀴.** 칩멍크가 쳇바퀴 안에 있고, 화면 아래 넓은 영역을 누르면 달린다. 달릴 때마다 캐는 종목의 코인 조각이 튀어 지갑으로 날아간다. 설비를 사면 쳇바퀴가 옆으로·위로 늘어난다(알바 칩멍크, 줄, 발전기, 헛간). 가압류 딱지는 쳇바퀴에 붙고, 압류되면 쳇바퀴째 수레에 실려 간다.
- **지갑 알약**: HUD의 현금 알약 옆에 둔다. `지갑 12,400 (▼3.1%)` — 도토리 환산값과 세대 시작 대비 등락. 누르면 일터 패널로 간다.
- **일터 패널**: 캐는 종목 고르기(4종 꼬리표), 지갑의 코인 수와 환산값, [팔기 전부 · 절반], '캐는 즉시 팔기' 스위치, 설비 목록(대수 · 캐는 값 · 전기세 · 지금 순수입, 역마진이면 빨간 딱지와 [끄기]).
- **거래 탭**: 포지션 줄 아래 한 줄 `지갑 도토코인 12,400어치 — 숏으로 지킨 비율 0%`. 보험이 얼마나 걸려 있는지만 보여 준다(권유 문구 없음).
- **정산 수지**: `캔 값 +5,700 / 전기세 −3,990 / 이자·생활비 −10,000`.

## 6. 방치 자산 (옛 서술 — 6A가 대체한다. 압류·담보·집과의 관계는 여전히 유효) [사용자 확정: 방향 / 제안: 규칙·숫자]

### 6.1 사다리
| 단계 | 자산 | 가격(첫 개) | 초당 수입 | 정산당 수입 | 정산당 수익률 | 여는 조건 | 칩멍크와 일터에 보이는 것 |

| 1 | 도토리 자루 | 20,000 | 9.5 | 1,710 | 8.6% | 처음부터 | 칩멍크가 자루를 멘다. 일터에 자루가 놓인다 |

| 3 | 청설모 알바 | 150,000 | 53.75 | 9,675 | 6.5% | 처음부터 | 일터에 청설모가 한 마리씩 는다 |

| 6 | 도토리 공방 | 8,000,000 | 1,700 | 306,000 | 3.8% | 창고 이상 | 굴뚝 달린 공방. 칩멍크가 조끼를 입는다. 조합 담보 가능 |
| 7 | 광장 상가 | 40,000,000 | 6,500 | 1,170,000 | 2.9% | 별장 이상 | 광장 옆 2층 상가. 칩멍크가 넥타이를 맨다. 조합 담보 가능 |

- 자산마다 3개까지. 둘째·셋째는 가격이 1.25배씩 오른다.
- **고정비** [제안]: 청설모 알바(3단계)부터는 인건비·자릿세·임대료가 평소 매출의 30%다. 표의 수입은 평소의 순수입이다. 경기가 나빠지면 매출만 줄고 고정비는 그대로라 순수입이 더 크게 준다(6.4).
- 수익률이 위로 갈수록 낮아진다. 싼 자산은 오소리 이자(4%)보다 벌이가 좋아서 "갚기 전에 산다"가 맞고, 비싼 자산은 캐피탈 이자(2%)보다 조금 나은 정도라 "빚내서 산다"가 아슬아슬하다.
- 수입은 초마다 들어온다. 자산 위로 `+9.5`가 쌓여 몇 초에 한 번 `+38`처럼 작게 떠오른다(귀여운 동작은 캐릭터와 그 소품에만).
- 정산이 3분이 되어 초당 수입은 4분의 1로 줄였고 정산당 수입은 그대로다.
- 노동 1회 수입 = 27 + 0.54 × 자산 초당 수입. 자산이 커질수록 누르는 맛도 커진다.

### 6.2 칩멍크와의 연결 (기억 메모: 클리커는 캐릭터와 연결)
- 사다리의 한 칸은 **칩멍크의 몸에 걸친 것 하나**(자루 → 수레 → 앞치마 → 조끼 → 넥타이)와 **일터 무대의 변화 하나**다.
- 가압류 딱지가 붙으면 그 소품에 딱지가 보인다(자루에 붙은 딱지를 멘 칩멍크). 압류되면 소품이 사라지고 칩멍크가 한 단계 전 모습으로 돌아간다. 삶이 나아지는 것도, 무너지는 것도 몸에서 보인다.
- "볼주머니 = 현금 게이지"는 쓰지 않는다(사용자 거절 유지).

### 6.4 경기 [제안]
지수(잣스닥)의 최근 정산 5회(15분) 수익률을 **평소의 15분 변동 폭(σ, 지나간 24시간 기준)**과 견준다. 고정 %가 아니라 평소 대비다 — 조용한 주에도 거친 주에도 비슷한 빈도로 온다.

| 경기 | 조건 | Hyperliquid 3.5일 기록에서 그 상태였던 시간 | 자루·수레의 수입 | 알바 이상(고정비 있음)의 순수입 |
|---|---|---|---|---|
| 공황 | −2σ 이하 | 2.8% | ×0.35 | ×0.07 |
| 불경기 | −1σ 이하 | 8.3% | ×0.6 | ×0.43 |
| 평소 | | 78.4% | ×1 | ×1 |
| 호황 | +1σ 이상 | 10.5% | ×1.3 | ×1.43 |

- 앞 개정의 고정 문턱(−0.5% / −1%)은 이 기록에서 불경기 1.3%, 공황 0.1%의 시간뿐이었다. 급변한 날의 기록에 맞춘 값이었다.
- 시장이 평소보다 크게 빠지는 시간에는 가게도 무너진다. 가게가 큰 사람에게 지수 숏은 보험이고, 지수 롱은 두 배로 거는 것이다.
- 빚내서 가게를 늘린 사람은 공황 몇 번에 이자를 못 낸다 — 방치 자산이 "절대 손해 안 보는 것"이 되지 않게 하는 장치다.

### 6.5 집 사다리와의 관계
- 집은 "사는 곳"이고 유지비만 나간다. 자산은 "버는 것"이다. 가공점부터는 주소(오두막 이상)가 있어야 열린다 — v1의 "주소지가 있어야 채용" 규칙이 자산으로 옮겨 왔다.
- 마을 색감은 v1처럼 집 단계를 따른다. 일터 무대는 가진 자산 중 가장 높은 단계를 따른다.

### 7.2 원인을 정하는 순서 (파산이 확정되면 위에서부터 처음 맞는 것)
1. 절교 3명으로 파산 → **FRIEND**
2. 청산 직후 즉시 파산이거나, 이번·직전 회차의 거래 실현 손실이 마지막 미납액 이상 → 그 손실 포지션에 정보 꼬리표가 있으면 **TIP**, 없으면 **LIQ**
3. 마지막 연체처가 세무서이거나, 남은 빚의 절반 이상이 승계 빚·세금 → **LEGACY**
4. 최근 정산 3회 안에 압류가 있었고 압류로 준 정산 수입이 마지막 미납액 이상 → **SEIZE**
5. 마지막 연체처가 집 유지비 → **UPKEEP**
6. 마지막 연체처가 조합·캐피탈 → **BANK**, 오소리·독사 → **SHARK**

**고르는 규칙**
1. 원인을 정한다(7.2).
2. 원인이 맞고 조건이 전부 참인 엔딩을 모은다. 기본 엔딩이 있으므로 비지 않는다.
3. 미수집이 있으면 그중 조건이 가장 많은 것 → 희귀도가 높은 것 → 번호가 작은 것.
4. 전부 수집한 것뿐이면 같은 순서로 하나를 다시 보여 주고 "n번째"로 센다.
5. v1의 '완성 보장 장치'(조건을 무시하고 주는 것)는 없앤다. 대신 7.5의 "한 끗 차이"가 길을 알려 준다.

**겹침과 희귀도가 세대를 건너 작동하는 방식**
- 같은 엔딩을 다시 얻으면 장부의 그 쪽에 "3대 ○○, 5대 △△"처럼 이름이 늘어난다. 보상은 없다.
- 같은 **원인**으로 2대 연속 망하면 기질이 '진한 피'가 된다. 3대 연속이면 전용 엔딩이 열린다(END-088, 150).
- 한 세대는 엔딩 하나만 준다. 200장은 최소 200세대가 아니라, 한 세대 10~25분 × 은퇴 없는 세대만 센 값이다. 빠르게 망하는 세대(200배 1분 30초)도 한 장이다. 일부러 빨리 망하는 것은 막지 않는다 — 대신 그 세대가 남기는 것이 없어 다음 세대가 가난하다.

### 7.5 플레이 중에 결말이 보이게 — 예고, 되짚기, 흔적
**(1) 예고 — "이대로 가면"** [제안]
- 기록관 건물에 등불이 있다. **지금 파산하면 받을 엔딩**이 미수집이면 등불이 켜진다. 기록관을 누르면 맨 위에 한 줄: `이대로 가면 → END-043 · ???  (독사 대부에게 빌린 직후 파산)`. 수집한 엔딩이면 제목이 보인다.
- 원인마다 3단계 조짐이 화면에 있다.

| 원인 | 조짐 | 경고 | 직전 |
|---|---|---|---|
| 청산·낚임 | 포지션 줄의 배율 딱지, 출처 꼬리표 | ROE −70%에서 깜빡임, 칩멍크 식은땀 | 청산가 꼬리표가 현재가에 붙음 |
| 사채 | 건물 머리 위 원금 | 연체 딱지 1/2, "수입 30% 가압류 중" | 오소리·독사가 일터 앞에 서 있음 |
| 제도권 | 창구의 독촉 대사 | 연체 딱지 n/3, 자산에 가압류 딱지 | 압류 수레가 마을 입구에 옴 |
| 유지비 | 우편함의 독촉장 1장 | 2장 | 대문에 경매 공고 |
| 압류 연쇄 | 자산 위 딱지 | 자산 하나가 실려 감 | 일터 무대가 한 단계씩 비어 감 |
| 관계 | 친구 말이 짧아짐 | 문 색이 바램, 절교 n/3 | 남은 친구가 문 앞에 나와 있음 |
| 대물림 | HUD 빚 알약의 '물려받은 빚' 띠 | 세무서 기한 타이머 | 세무서 공매 딱지 |

**(2) 되짚기 — 엔딩 화면의 "마지막 세 장면"** [제안]
- 게임은 중요한 행동을 **사건 기록**에 남긴다(최근 12개): 대출, 도장, 거절, 이자 미루기, 제안 수락, 정보를 봄, 진입(배율·출처), 물타기, 청산, 연체, 딱지, 압류, 절교, 이사, 자산 매매, 유품 전당.
- 엔딩 화면은 그림·대사 아래에 그중 마지막 세 개를 시각과 함께 그대로 보여 준다.
```
정산 12회차 저녁  족제비 대표 추천: 밤더리움 롱
        8초 뒤   밤더리움 롱 100배 진입 (현금의 100%)
       31초 뒤   강제 청산 −84,000 → 오소리 대부 이자 6,000 미납 (2/2)
```
- 그 아래 **"한 끗 차이"**: 조건 하나만 달랐으면 받았을 미수집 엔딩을 최대 2개. `손절을 걸어 뒀더라면 → END-191 · ???`
- 맨 아래 **"다음 세대에 남는 것"**: 기질, 유품 변화, 마을의 흔적 한 줄씩.

**(2-1) 자고 일어나니 — 포지션 방치의 예고와 되짚기** [사용자 확정: 방향 / 제안: 세부]
- **나갈 때**(앱이 가려지는 순간, 열린 포지션이 있으면) 속보 띠에 한 줄: `열어 둔 포지션 2개 — 자리를 비워도 계속 움직입니다. 가장 가까운 청산가까지 0.4%`. 권유도 경고도 아닌 사실 문장이다.
- **돌아왔을 때** 가장 먼저 "자리를 비운 사이" 시간표가 뜬다. 비운 구간 전체의 차트를 한 화면에 줄여 그리고, 일어난 일을 실제 시각 순서로 적는다.
```
자리를 비운 사이 — 7시간 52분
  23:14  밤더리움 롱 200배를 걸어 두고 나감 (증거금 42,000)
  01:27  밤더리움 강제 청산 −42,000          ← 나간 지 2시간 13분
  01:27  도토코인 숏 100배 익절 +18,600
  (정산은 2회만 돌았습니다: 자산 수입 +3,420 / 이자 −18,000)
```
- 청산으로 빈손이 되어 파산이 정해졌으면 시간표 다음에 엔딩으로 넘어간다. 엔딩의 "마지막 세 장면"은 이 시간표의 마지막 세 줄이고, 조건 `offline`, `awayHours`가 엔딩을 가른다(END-164 걸어 두고 나간 사이 / END-186 둘 이상 / END-196 200배를 6시간 넘게 — 자고 일어나니).
- 시뮬레이션: 자산 없이 200배로만 거래하는 유형의 파산 가운데 55.2%가, 200배 한 방 유형의 56.1%가 자리를 비운 사이에 정해졌다.

### 7.6 도감 단서
- 미수집 칸: `END-043 · ???` + 원인 아이콘 + **행동 문장 단서**(CSV의 `clue`). 조건식이 아니라 "무엇을 하면 되는지"를 쓴다.
- ★3 엔딩은 조건 하나를 `?`로 가린다. 같은 원인의 이웃 엔딩(조건 하나를 함께 쓰는 엔딩)을 모으면 열린다.
- 수집 칸: 제목, 대사, 그림, 몇 대 누구, 마지막 세 장면.
- 거르기: 원인 8개 / 희귀도 / "이번 세대에 노릴 수 있는 것"(세대 조건이 맞는 것만).

### 7.7 수용 기준 — 엔딩

## 9. 구현할 때 손대는 곳 (참고)
- 새 엔진 모듈: `generation.ts`(상속·세금·기질), `assets.ts`(자산·딱지·압류), `feed.ts`(게임 서버의 틱 WebSocket 받기, 끊김 처리, 서버 틱 REST로 메우기), `tips.ts`(속보·NPC 규칙·정보 수첩), `eventlog.ts`(사건 기록). 엔진은 여전히 순수 함수다 — 시세 틱을 입력으로 받을 뿐 네트워크를 모른다. 테스트는 기록 시세로 돌린다.
- 고치는 모듈: `settlement.ts`(생활비·딱지·압류 단계), `bankruptcy.ts`(원인 8개), `endings.ts`(조건 평가·선택·한 끗 차이), `labor.ts`, `offline.ts`, `market.ts`(난수 모델은 테스트용으로 남김).
- **서버(신규)**: `server/source-hyperliquid.ts`·`server/source-dex.ts`(시세 출처 어댑터), `server/failover.ts`(자동 전환), `server/transform.ts`(가상 종목 변환·지수), `server/ticks-store.ts`(틱 기록), `server/broadcast.ts`(앱으로 방송, 시장 상태), `server/ticks-api.ts`(지난 구간), `server/ranking-verify.ts`(체결 기록 대조). 미국 밖 지역에 둔다. v1 GDD 19장(서버 없음)과 14장(저장·오프라인), 13장(랭킹)에 영향.
- 데이터: `data/endings.json`의 `trigger`를 `endings_v2_map.csv`의 `cause`·`modifiers`로 바꾼다. `data/assets.json`, `data/tips.json`, 테스트용 틱 조각 신설(앱에는 넣지 않는다).
- 저장: `fof.save.v2` — `family: { generation, ledger, peakNetWorth, traits, heirlooms, tipBook, lenderRelations, traces, tree }` + `run`. v1 저장은 2세대의 진행 중 회차로 옮긴다.

| A | **거래로 이기는 사람이 너무 드물다** — 확정된 역할("빠르지만 대부분 망하는 거래")에서 '대부분 망한다'는 맞지만(99.4~100%), 이기는 쪽이 0.5~0.7%뿐이다. 모든 정보의 평균이 −15 ~ −29%(100배·8시간)라서다. 보험(자산 + 숏)도 효과가 재지지 않았다 | 거래가 "해 볼 만한 도박"이 아니라 "그냥 지는 길"로 읽힐 수 있다 | 이기는 쪽을 5~15%로 올리는 조정을 권한다: ① 수수료 0.04% → 0.02%(100배 왕복 8% → 4%) ② 익절 단계에 +300·+1,000% 추가(드물게 크게) ③ 거래만 하는 사람의 이자 부담을 줄일 방법(걸어 두고 나가면 경제가 정산 2회에서 멈추므로 이미 일부 작동한다). 보험은 공황 때 자산 순수입이 ×0.07까지 떨어지는 구간에서만 값을 하므로 서버 기록이 쌓인 뒤 다시 잰다 |
