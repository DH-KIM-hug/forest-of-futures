# sim_v3 — 엔진 직접 호출 시뮬레이션 (M4)

엔진: `src/engine/*` 를 그대로 호출(`stepMut`·`catchUp`·`declareBankruptcy`·상속 액션). 시세: `hl_3m.json` ReplayFeed(1초 틱, 기록 안 시작 위치만 런마다 다름). 하루 5번 × 6~9분 접속. 런 12회, 최대 336시간. 빚을 다 갚은 뒤 6시간 더, 그리고 세대 시작부터 72시간이 지난 첫 접속에서 세대를 끝낸다(스크립트 — 엔진의 파산 함수 호출).
